# SRdeck plugin platform packages

These packages provide the contracts, SDK helpers, shared WPF controls, and signal-processing components used to build plugins for the matching SRdeck release. Keep all four packages on the same version as the target host; do not mix artifacts from different releases.

The packages are GPL-3.0-only. Review `LICENSE`, `THIRD-PARTY-NOTICES.md`, `SECURITY.md`, and `PATENT-NOTICE.md` in each package before use or redistribution.

Documentation and release artifacts: <https://github.com/sake846/SRdeck>
