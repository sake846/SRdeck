# 地図とオフライン地図

SRdeckの地図は、位置情報を持つ航空機、船舶、局、ノードなどを表示します。地図ソースの設定は全プラグインで共通です。このページでは、オンライン地図、閲覧済みキャッシュ、ラスターMBTilesによるオフライン地図の使い分けを説明します。

## 必要なもの

- 地図を表示するにはMicrosoft Edge WebView2 Runtimeが必要です。
- 未表示地域をオンラインで開くにはHTTPS通信が必要です。
- オフライン地図には、PNG、JPEG、またはWebP画像を格納したラスターMBTilesが必要です。
- 地図に表示する対象自体が有効な緯度経度を持っている必要があります。

Leaflet本体はSRdeckに同梱されています。地図を持たないプラグインや、位置情報をまだ受信していない対象は地図に表示されません。

## 地図の基本操作

1. `MODE`から、AIS、ADS-B、ACARS、HFDL、VDL Mode 2、FT8など地図を持つプラグインを選びます。
2. 右ペインの`地図`タブを開きます。
3. ドラッグで移動し、マウスホイールまたは`+`／`-`で拡大・縮小します。
4. マーカーを選択すると、対象名、詳細、緯度経度を確認できます。
5. 地図右上に表示される場合は、`航跡`やラベルのチェックを切り替えます。

最後に表示した中心位置とズームはプラグインごとに保存されます。地図ソースとMBTilesの選択は全プラグインで共通です。

## 地図ソースを設定する

メイン画面左下の`設定`を開き、`地図`タブを選択します。

| モード | 動作 | 主な用途 |
|---|---|---|
| `自動` | 接続中は有効なキャッシュまたはオンライン地図を使用します。ネットワークが利用できない場合は、有効なキャッシュ、続いて設定済みMBTilesを使用します。オンライン取得に失敗した場合も、MBTilesがあれば切り替えます。 | 通常利用 |
| `オンライン` | 有効なキャッシュを再利用し、必要なタイルをオンラインで取得します。MBTilesへは切り替えません。 | 常に最新のオンライン地図を使いたい場合 |
| `オフライン` | MBTilesが設定済みなら、そのファイルだけを使用してOpenStreetMapへ接続しません。MBTilesが未設定の場合は、有効期限内の閲覧済みキャッシュだけを使用します。 | 閉域環境、位置情報を外部へ送信したくない場合 |

`オフライン`へ切り替える前に、使用するMBTilesの収録地域とズーム範囲を確認してください。収録されていない地域や縮尺へ移動すると通知を表示し、直前に正常表示できた位置へ戻ります。

## 配布済みMBTilesをダウンロードする

SRdeckは、提供元が配布を許可しているラスターMBTilesを、直接HTTPS URLからダウンロードできます。

1. 配布元で対象地域とデータセットを選び、`.mbtiles`ファイル本体のHTTPS URLを取得します。
2. `設定` → `地図`を開きます。
3. `MBTilesダウンロードURL`へURLを貼り付けます。
4. `ダウンロード`を押します。
5. 保存先とファイル名を選びます。
6. 進捗が100%になり、`有効: 名前 / 形式 / ズーム範囲`と表示されることを確認します。
7. ネットワークへ接続せず使用する場合は、地図モードを`オフライン`にします。

ダウンロード中は`キャンセル`で中止できます。SRdeckは一時ファイルへストリーミング保存し、互換性を検証できた場合だけ指定した保存先へ反映します。失敗またはキャンセル時は一時ファイルを削除し、同名の既存ファイルは置き換えません。

ダウンロード開始時に地図モードが`オンライン`だった場合は、取得したMBTilesを利用できるよう`自動`へ切り替わります。完全なオフライン動作が必要なら、完了後に`オフライン`を選択してください。

### URLについて

使用できるのはファイル本体を返すHTTPS URLです。次のURLは使用できません。

- 配布元の説明ページやログインページ
- `.zip`、`.7z`など圧縮ファイルのURL
- `https://.../{z}/{x}/{y}.png`形式の個別タイルURL
- HTTP URL、またはユーザー名・パスワードを埋め込んだURL

認証付きURLや期限付きURLで`401`、`403`になる場合は、Webブラウザーでファイルをダウンロードし、次の「手元のMBTilesを選択する」の手順を使用してください。

## 手元のMBTilesを選択する

Webブラウザー、QGIS、または別の端末で取得・作成したファイルも利用できます。

1. `設定` → `地図`を開きます。
2. `MBTilesファイル`の`参照...`を押します。
3. `.mbtiles`ファイルを選択します。
4. 名前、画像形式、最小・最大ズームが`有効`として表示されることを確認します。
5. 必要に応じて地図モードを`自動`または`オフライン`にします。

ファイルを選択後に移動、改名、削除すると利用できなくなります。長期利用するファイルは、書き込み可能でバックアップ対象にできる固定フォルダーへ保存してください。

## 配布元と作成方法の例

配布内容、価格、認証方法、利用条件は変更されることがあります。取得前に各提供元の最新情報を確認してください。

### MapTiler Data

[MapTiler Dataのダウンロード手順](https://docs.maptiler.com/guides/self-hosting/self-hosted-maps/how-to-download-data-from-maptiler-website/)では、全世界、国、地域、または任意範囲のMBTilesを取得できます。

SRdeckで利用できる例:

- Satellite raster tiles（JPG）
- Hillshading raster tiles
- Satellite Lowres raster tiles

ダウンロード画面または案内される`wget`コマンドから、`https://...mbtiles`部分だけをコピーしてSRdeckへ入力します。サインイン、ライセンスへの同意、またはデータと範囲に応じた料金が必要な場合があります。

MapTilerのOpenStreetMap tilesはベクトル形式です。現在のSRdeckでは道路地図用のベクトルMBTilesを描画できないため、`OpenStreetMap vector tiles`、`Contour lines vector tiles`、`Landcover`は選択しないでください。

### OpenSeaMap

[OpenSeaMapのラスターMBTiles一覧](https://ftp.gwdg.de/pub/misc/openstreetmap/openseamap/charts/mbtiles/)では、海域別のオフライン海図が配布されています。AISなど船舶向けの背景地図として利用できます。

- 日本周辺を探す場合は、一覧の`EastChineseSea`など収録範囲の近いファイルを確認します。
- 一覧上の`.mbtiles`リンクを右クリックし、リンク先をコピーしてSRdeckへ入力できます。
- ファイルは数百MBから数GBになるため、収録範囲と空き容量を先に確認してください。
- 海図用途のため、一般的な道路地図の代替にはなりません。

OpenSeaMapのデータ内容、表示、ライセンス、航海利用上の注意は配布元の案内に従ってください。

### QGISで作成する

希望する一般地図のラスターMBTilesが配布されていない場合は、利用・複製・オフライン保存が許可されたデータをQGISへ読み込み、自分で作成できます。

1. QGISで使用許可のある地図レイヤーを構成します。
2. `Processing Toolbox` → `Raster tools` → `Generate XYZ tiles (MBTiles)`を開きます。
3. 出力範囲、最小・最大ズームを指定します。
4. タイル形式にPNGまたはJPGを選びます。
5. 出力先を`.mbtiles`として保存します。
6. SRdeckの`参照...`から作成したファイルを選びます。

詳しいパラメーターは[QGIS公式ドキュメント](https://docs.qgis.org/3.44/en/docs/user_manual/processing_algs/qgis/rastertools.html#generate-xyz-tiles-mbtiles)を参照してください。オンラインタイルを入力にする場合でも、一括取得とオフライン保存が提供元の規約で許可されていることを確認してください。

## 対応形式と非対応形式

MBTilesは入れ物の仕様で、内部には画像またはベクトルタイルを格納できます。拡張子だけでは互換性を判断できません。

| 内容 | 対応状況 |
|---|---|
| PNGラスターMBTiles | 対応 |
| JPEG／JPGラスターMBTiles | 対応 |
| WebPラスターMBTiles | 対応 |
| PBF／MVTベクトルMBTiles | 非対応 |
| PMTiles | 非対応 |
| GeoPackage（`.gpkg`） | 非対応 |
| Mapsforge（`.map`）、OsmAnd（`.obf`） | 非対応 |
| OpenStreetMap生データ（`.osm.pbf`） | 非対応 |

GeofabrikやBBBikeなどで配布される`.mbtiles`には、PBFベクトルタイルのものがあります。メタデータの`format`が`pbf`なら現在のSRdeckでは使用できません。

## オンライン地図キャッシュ

オンライン表示で実際に閲覧したOpenStreetMapタイルは、提供元のキャッシュ有効期限に従って最大512 MBまで保存されます。

- 地域やズームを先回りして一括取得する機能ではありません。
- 有効期限が切れると、オフラインでは表示できなくなる場合があります。
- 容量上限を超えると、古く利用頻度の低いタイルから削除されます。
- `設定` → `地図` → `キャッシュ消去`で全タイルを削除できます。

長期間確実にオフライン利用する場合は、閲覧済みキャッシュではなくラスターMBTilesを用意してください。

## ライセンス、通信、プライバシー

- `tile.openstreetmap.org`では、地域や複数ズームの一括取得、プリフェッチ、オフライン用アーカイブ作成が禁止されています。SRdeckのオンライン地図は現在の表示範囲だけを取得します。詳細は[OpenStreetMap Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)を確認してください。
- MBTilesの取得、複製、保存、再配布が許可されているか、配布元の利用条件を確認してください。
- 必要なクレジットがMBTilesの`attribution`メタデータに含まれていることを確認してください。SRdeckはこの値を地図上へ表示します。
- オンライン地図の表示時は、OpenStreetMapへIPアドレスと表示地域に対応するタイル座標が送信されます。
- URLダウンロード時は、指定した配布元へIPアドレスが送信されます。
- 外部への地図通信を止めたい場合は、地図を開く前にモードを`オフライン`へ設定してください。

## 表示できないとき

| 症状 | 確認すること |
|---|---|
| 地図画面自体を開始できない | WebView2 Runtimeがインストールされているか |
| ダウンロードが`401`または`403`になる | URLの認証や有効期限。ブラウザーで取得して`参照...`を使用できるか |
| ダウンロード後に「使用できません」と表示される | URLがHTMLや圧縮ファイルではなく、PNG／JPEG／WebPのラスターMBTiles本体か |
| ある縮尺だけ背景が出ない | MBTilesの最小・最大ズーム範囲内か |
| ある地域だけ背景が出ない | MBTilesの収録範囲内か |
| 背景は出るが対象が出ない | `一覧`や`時系列`に有効な緯度経度があるか |
| オフラインでキャッシュが消えた | 提供元の有効期限切れ、または512 MB上限による削除でないか |
| 選択済みファイルが利用できない | ファイルを移動・改名・削除していないか、読取権限があるか |

解決しない場合は[トラブルシューティング](Troubleshooting#地図が表示されない)も確認してください。
