# CW Skimmer

`CW Skimmer`（プラグインID: `cw`）は、選択した帯域内の複数のCW信号を検出・追尾し、モールス符号をリアルタイムに文字へ変換する公式プラグインです。`with-plugins`パッケージに含まれます。

## 主な機能

- 10／20／50 kHzの受信帯域と、帯域に対応する10／20／50 kS/sの標準チャネルIQ
- FFTピーク追尾による複数信号の同時検出
- 5～60 WPMに追従する適応モールスタイミング復号
- 欧文／和文の選択、自動コールサイン抽出、アクティビティ追尾
- 周波数オーバーレイとウォーターフォール注釈
- 選択信号の800 Hzモニター音声
- JSONL履歴、CSV／JSONエクスポート、直前10秒のIQキャプチャ

## 最初の受信

1. `MODE`で`CW Skimmer`を選びます。
2. 受信したい周波数を設定し、混雑度に応じて10／20／50 kHzの帯域を選びます。
3. `Start`後、ウォーターフォール上の信号と復号行を確認します。
4. 必要に応じて言語、最小／最大WPM、検出しきい値、モニター音量を調整します。

狭い帯域は処理負荷と不要信号を減らし、広い帯域は同時に探索できる範囲を増やします。結果が不安定な場合は、信号を帯域中央付近へ置き、ゲイン過大、周波数ずれ、混信を先に確認してください。

## 画面と保存

復号結果には周波数、速度、SNR、復号文字列が表示されます。ウォーターフォール注釈は文字を受信位置と時刻へ対応付けるための表示であり、IQそのものを保存する機能ではありません。

`IQ 録音 (直前10秒)`は受信中に保持している標準チャネルIQをWAVと診断JSONへ保存します。保存先は通常、次のフォルダーです。

```text
%LOCALAPPDATA%\SRdeck\plugins\cw\captures
```

## 受信上の注意

- 自動復号は短点／長点の間隔、フェージング、キーイング品質、複数信号の重なりに影響されます。
- 表示されたコールサインは自動抽出結果なので、元の復号文字列と合わせて確認してください。
- モニター音声は復号対象の確認用です。Windowsの既定出力デバイスへ送られます。
