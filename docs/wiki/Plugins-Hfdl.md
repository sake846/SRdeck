# HFDLプラグイン

プラグインIDは`hfdl`です。HF Data Linkを受信し、ARINC 635のSPDU／LPDUエンベロープ、Flight ID、位置、復号結果、生Payloadを解析します。

## 受信経路

```text
選択したHFDL地上局チャネル
  -> 信号中心: 公称周波数 + 1,440 Hz
  -> 14.4 kS/s IQ
  -> 1,800 symbol/s BPSK / QPSK / 8PSK
  -> prekey / preamble / M1 / M2
  -> 位相デスクランブル / デインターリーブ
  -> K=7 Viterbi / CRC
  -> SPDU / LPDU解析
```

プラグインは3 kHz地上局チャネルを選択し、4.8 kHzの標準チャネルを信号中心へ要求します。

## HF伝搬と周波数選択

HFDLの受信可否は地上局、距離、時刻、季節、電離層状態、アンテナに左右されます。設定画面には地上局、周波数、時間帯の伝搬目安が表示されます。

- 低い周波数: 夜間や長い経路で有利になることがある
- 高い周波数: 日中や高いMUFで有利になることがある
- 実際の運用: 地上局が周波数を随時変更する
- 信号中心: 表示された公称周波数に+1,440 Hz

伝搬目安は保証ではありません。複数候補を時間を置いて比較し、`診断`の信号品質と同期を確認します。

## 最初の受信

1. HF帯に合うアンテナとSDR設定を準備します。
2. `MODE`で`HFDL`を選びます。
3. 地域／距離／時間帯に合いそうな地上局を選びます。
4. その地上局の周波数候補を選びます。
5. 必要ならモニター音声を有効にします。
6. `Start`を押します。
7. スペクトラムで公称周波数+1,440 Hz付近の信号を確認します。
8. `診断`でprekey、preamble、M1／M2、Viterbi、CRCの順に確認します。
9. 受信できない場合は、同じ地上局の別周波数または別地上局を試します。

HFではノイズやフェージングが時間で変わるため、短時間で周波数を次々変えるより、診断を見ながら一定時間観測します。

## ワークスペース

### 概要

受信機体数、有効フレーム、合格率、最終受信、最近のFlight IDを表示します。

### 一覧

Flight ID別と、メッセージ種別別の集約を切り替えて確認できます。最新内容、件数、最終受信を比較し、詳細ペインで解析結果を読みます。

### 時系列

各HFDLイベントの日時、地上局／周波数、Flight ID、SPDU／LPDU、検証結果、Payload／Raw frameを表示します。

### 地図

位置を含むメッセージを受信・解釈できた機体を表示します。すべてのフレームが位置情報を含むわけではありません。

### 診断

入力・選局、信号、prekey／preamble、同期、変調、Viterbi、CRCを段階別に表示します。同期前で止まる場合とCRCで止まる場合を分けて調整できます。

## モニター音声

選択チャネルを聞き、信号の有無、フェージング、干渉を把握できます。現行画面にプラグイン個別の音量スライダーはないため、全体音量はWindows側で調整します。音の印象だけで復号可否を断定せず、同期とCRCを確認してください。

## 履歴設定

| 設定 | 既定値 | 有効範囲／意味 |
|---|---:|---|
| 最大表示機数 | 500 | 50～5000 |
| 機体非表示時間 | 30分 | 1～1440分 |
| 航跡保持点数 | 100 | 10～1000 |
| 履歴保持件数 | 10,000 | 100～100,000 |

## よくある症状

### 信号が見つからない

時間帯と伝搬に合う別周波数を試します。アンテナ、プリアンプ／アッテネーター、HF帯の強い放送局による過入力も確認します。

### prekeyは出るがpreambleが成立しない

周波数中心、PPM、フェージング、SNRを確認します。信号中心が公称周波数+1,440 Hzである点も確認してください。

### Viterbi後にCRCが通らない

ゲイン、干渉、マルチパス、深いフェージングを確認します。短いIQキャプチャと診断JSONを保存すると比較に役立ちます。

### 機体が地図に出ない

位置を含むLPDUをまだ受信していない、解釈未対応、保持期限、WebView2を確認します。
