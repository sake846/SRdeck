# 地図とキャッシュ

SRdeckの地図は、位置情報を持つ航空機、船舶、局、ノードなどを表示します。地図タイルはオンラインで取得して端末内にキャッシュし、通信できないときは閲覧済みタイルを表示します。ユーザーが別の地図データを選択・ダウンロードする機能はありません。

## 地図モード

基幹画面の`設定`にある`地図`タブで選択します。モードは全プラグインで共通です。

| モード | 動作 |
| --- | --- |
| `自動` | 接続中はOpenStreetMapのタイルを取得・更新します。通信できないときや取得に失敗したときは、キャッシュ済みタイルを表示します。 |
| `キャッシュのみ` | 接続状態にかかわらずネットワークへ地図タイルを要求せず、キャッシュ済みタイルだけを表示します。 |

地図の中心位置とズームはプラグインごとに保存されます。タイルキャッシュと地図モードは共通です。

## オフラインで表示できる範囲

キャッシュには、オンラインで実際に表示した地域とズームのタイルだけが保存されます。外出前に必要な地域と縮尺を表示してください。表示範囲を一括ダウンロードしたり、先読みしたりする機能はありません。

キャッシュの上限は512 MBです。空き容量が足りない場合は、最後に使われた時刻が古いタイルから削除されます。オフラインではキャッシュ済みタイルの有効期限が過ぎていても表示します。キャッシュから削除された地域・縮尺や、まだ表示したことがない地域は表示できません。

## 通信とプライバシー

オンラインで新しいタイルを取得したり、キャッシュを更新したりするときは、OpenStreetMapのタイルサーバーへHTTPS接続します。リクエストから接続元IPアドレスと表示地域のおおよその範囲が分かります。地図通信を行わない場合は、地図を開く前にモードを`キャッシュのみ`へ設定してください。

SRdeckは表示範囲に必要なタイルだけを要求し、OpenStreetMapのタイルを一括取得・再配布しません。地図上にはOpenStreetMapの著作権表示を常に表示します。詳細は[OpenStreetMapタイル利用ポリシー](https://operations.osmfoundation.org/policies/tiles/)を確認してください。

## キャッシュの管理

`設定` → `地図`で、キャッシュの容量とタイル数を確認したり、キャッシュを消去したりできます。`キャッシュを確認`を押すと、縮尺ごとのタイル数と期限切れ数に加えて、各タイルの中心座標、保存からの経過時間、有効期限が表示されます。

管理画面には2つの地図があります。

| 地図 | 役割 |
|---|---|
| 左上 | 保存済みタイルの分布を確認・選択する |
| 右 | 通常の地図表示やタイルの取得に使う |

右の地図の縮尺を変えると、左上で確認する対象タイルの縮尺も切り替わります。左上の地図自体の表示倍率は独立しているため、右の地図を拡大・縮小しても広域表示を保てます。

### 保存済みタイルを確認する

- 左上の地図には、選択した縮尺のタイルを実際の位置と大きさで表示します。縮小表示でも、隣り合うタイルをまとめません。
- 広域ではタイルが小さく見分けにくくなります。必要に応じて左上の地図を拡大してください。一度に表示できる数を超えた場合も、拡大を促す案内が表示されます。
- キャッシュがない縮尺は「0 タイル」と表示します。ある縮尺のタイルが保存済みでも、別の縮尺では未保存の場合があります。

**色の見方:**

| 色 | 状態 |
|---|---|
| 緑 | 有効なキャッシュ |
| 橙 | 有効期限切れのキャッシュ |
| 青 | 選択位置 |
| 紫 | 右の地図の表示範囲 |

- 通常時に左上の場所をクリックすると、右の地図がその位置へ移動します。タイルの枠をクリックすると、左下の一覧で該当行が選択され、右の地図もそのタイルへ移動します。
- 一覧でタイルを選ぶと、左上の地図に青い枠または印が表示されます。`選択位置を右へ`を押すと、右の地図がその位置へ移動します。
- 有効期限が過ぎたタイルも、オフラインでは表示できます。

### タイルを削除・更新する

1. 部分削除するには、左上の`削除モード`を有効にします。
2. 削除するタイルをクリックして選択します。もう一度クリックすると選択を解除できます。削除モード中は空白部分をクリックしても右の地図は移動しません。
3. `選択分を削除`を押して内容を確認し、削除を確定します。キャッシュ一覧と地図が更新されます。

`右の地図をオンライン表示`を有効にすると、管理画面の右の地図を手動で移動・拡大したときに、表示範囲に必要な**右の地図ズーム**のタイルを取得します。この設定は管理画面の右の地図に限り、共通の地図モードより優先されます。左上の地図はキャッシュのみを使います。

`地図表示中のタイルを更新`は、右の地図の縮尺と表示範囲を対象にします。左で選んだ縮尺のタイルを追加・更新するには、削除モードを解除して左上の地図をクリックしてください。

管理画面を開いた直後は通信しません。一括取得や先読みも行いません。キャッシュを消去すると、次にオンラインで表示したタイルが保存されるまで、オフラインでは地図を表示できません。

## 地図が表示されない場合

| 症状 | 確認すること |
| --- | --- |
| オフラインで背景が表示されない | その地域・ズームを以前オンラインで表示したか、キャッシュが上限に達して古いタイルが削除されていないか確認します。 |
| オンラインでも背景が表示されない | ネットワーク接続とタイル提供元へのHTTPS接続を確認します。 |
| 地図機能自体が読み込まれない | Microsoft Edge WebView2 Runtimeが利用可能か確認します。 |
| 航空機や船舶などのマーカーが表示されない | 一覧に緯度・経度があるか確認します。背景タイルのキャッシュとは別の状態です。 |
