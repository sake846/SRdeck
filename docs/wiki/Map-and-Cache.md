# 地図とキャッシュ

SRdeckの地図は、位置情報を持つ航空機、船舶、局、ノードなどを表示します。地図タイルはオンラインで取得して端末内にキャッシュし、通信できないときは閲覧済みタイルを表示します。ユーザーが別の地図データを選択・ダウンロードする機能はありません。

## 地図モード

基幹画面の`設定`にある`地図`タブで選択します。モードは全プラグインで共通です。

| モード | 動作 |
| --- | --- |
| `自動` | 接続中はOpenStreetMapのタイルを取得・更新します。通信できないときや取得に失敗したときは、キャッシュ済みタイルを表示します。 |
| `キャッシュのみ` | 接続状態にかかわらずネットワークへ地図タイルを要求せず、キャッシュ済みタイルだけを表示します。 |

地図の中心位置とズームはプラグインごとに保存されます。タイルキャッシュと地図モードは共通です。

## オフラインで表示できる範囲

キャッシュには、オンラインで実際に表示した地域とズームのタイルだけが保存されます。外出前に必要な地域と縮尺を表示してください。表示範囲を一括ダウンロードしたり、先読みしたりする機能はありません。

キャッシュの上限は512 MBです。空き容量が足りない場合は、最後に使われた時刻が古いタイルから削除されます。オフラインではキャッシュ済みタイルの有効期限が過ぎていても表示します。キャッシュから削除された地域・縮尺や、まだ表示したことがない地域は表示できません。

## 通信とプライバシー

オンラインで新しいタイルを取得したり、キャッシュを更新したりするときは、OpenStreetMapのタイルサーバーへHTTPS接続します。リクエストから接続元IPアドレスと表示地域のおおよその範囲が分かります。地図通信を行わない場合は、地図を開く前にモードを`キャッシュのみ`へ設定してください。

SRdeckは表示範囲に必要なタイルだけを要求し、OpenStreetMapのタイルを一括取得・再配布しません。地図上にはOpenStreetMapの著作権表示を常に表示します。詳細は[OpenStreetMapタイル利用ポリシー](https://operations.osmfoundation.org/policies/tiles/)を確認してください。

## キャッシュの管理

`設定` → `地図`では、キャッシュ容量とタイル数を確認し、キャッシュを消去できます。`キャッシュを確認`を押すと、縮尺ごとのタイル数と期限切れ数、各タイルの中心座標・保存からの経過時間・有効期限を確認できます。左上の地図はキャッシュ分布の確認用、右の地図は実際の表示・取得用です。右の地図の縮尺を変えると、左の確認対象も同じ縮尺に変わります。左上の地図の縮尺は独立しているため、広域表示を維持できます。

左上には、選択した縮尺で保存済みのタイルを実際の位置と大きさで表示します。縮小しても隣り合うタイルをまとめません。広域では詳細タイルが小さくなるため、見分けにくい場合は左上を拡大してください。一度に表示できる数を超えた場合も拡大を促します。通常時に左上の場所やタイルをクリックすると、右の地図が対象縮尺でその位置へ移動します。キャッシュがない縮尺も 0 タイルとして表示されます。縮尺ごとに別のタイルが必要で、ある縮尺でキャッシュ済みでも、拡大・縮小先の縮尺では未キャッシュの場合があります。緑は有効なキャッシュ、橙は有効期限が過ぎたキャッシュ、青は選択位置、紫は右の地図の表示範囲です。実タイルの枠をクリックすると左下の該当行が選択され、右の地図もそのタイルへ移動します。期限切れでもオフラインで表示できます。

部分削除する場合は、左上の`削除モード`を有効にし、不要なタイルを地図上でクリックして選択してから`選択分を削除`を押します。タイルをもう一度クリックすると選択を解除できます。削除モード中に空白部分をクリックしても右の地図は移動しません。選択分を確認して削除を確定すると、キャッシュ一覧と地図の表示が更新されます。一覧でタイルを選ぶと左上の地図に青い枠または印で示され、`選択位置を右へ`で右の地図をその位置へ移動します。`右の地図をオンライン表示`を有効にして右の地図を手動で移動・拡大すると、**右の地図ズーム**のタイルが追加されます。左上の確認地図はこのスイッチを入れてもキャッシュのみを使います。このスイッチは管理画面の右の地図に限り共通の地図モードより優先されます。`地図表示中のタイルを更新`も右の地図ズームと現在の表示範囲が対象です。左で選んだ縮尺のタイルを追加・更新するには、削除モードを解除して左上の地図をクリックしてください。管理画面を開いた直後は通信しません。OpenStreetMap タイルの一括取得や先読みは行いません。消去後にオフラインで表示できるのは、次にオンラインで表示したタイルだけです。

## 地図が表示されない場合

| 症状 | 確認すること |
| --- | --- |
| オフラインで背景が表示されない | その地域・ズームを以前オンラインで表示したか、キャッシュが上限に達して古いタイルが削除されていないか確認します。 |
| オンラインでも背景が表示されない | ネットワーク接続とタイル提供元へのHTTPS接続を確認します。 |
| 地図機能自体が読み込まれない | Microsoft Edge WebView2 Runtimeが利用可能か確認します。 |
| 航空機や船舶などのマーカーが表示されない | 一覧に緯度・経度があるか確認します。背景タイルのキャッシュとは別の状態です。 |
