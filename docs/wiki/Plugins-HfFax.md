# HF-FAXプラグイン

`HF-FAX`（プラグインID: `hffax`）は、HF気象無線模写（Weather Fax／Wefax）を受信し、グレースケール画像を生成する公式プラグインです。`with-plugins`パッケージに含まれます。

## 主な機能

- 割当周波数を中心とした3.0 kHz帯域、12 kS/sの標準チャネルIQ
- 1900 Hzを中心とするF3C信号（1500 Hz=黒、2300 Hz=白）の復調
- 300／675 HzのAPT開始信号と450 Hzの停止信号の検出
- IOC 576／288、60／90／120 LPM
- 手動開始／停止、傾き、横位置、ライン毎同期の補正
- OFF／600／1200／1800 HzのVBWフィルター
- 受信信号のモニター音声、画像履歴、PNG保存

## 最初の受信

1. `MODE`で`HF-FAX`を選びます。
2. 局プリセットを選ぶか、既知の割当周波数へ合わせます。
3. 放送スケジュールに合わせて`Start`し、診断で信号とAPT検出を確認します。
4. APT開始信号を受信できない場合は手動開始を使います。
5. 画像が斜めならppm／傾きを、左右にずれる場合は横位置を補正します。
6. 必要な画像を選び、PNGとして保存します。

短波の伝搬は時刻、季節、場所、アンテナ、混信の影響を強く受けます。まず対象局の運用周波数と時刻を確認し、USBの音声スペクトルで1900 Hz付近へ信号が来るように選局してください。

## 同期と画像補正

位相信号を受信できた場合、プラグインはその基準を保持して走査線の横位置を整列します。位相信号より後から受信した場合や、位相信号を送らない局では手動補正が必要です。

`ライン毎同期補正`は画像中の同期パルスへ追従し、欠落中は直前のライン位相を保持します。同期パルスを送らない局では無効にし、フェージング測定値と手動ppm補正を使います。同期状態、検出数、欠落補間数、受信周期偏差は`診断`で確認できます。

## 保存と音声

完成画像はプラグイン履歴へ保持され、画面上では縮小表示されます。PNGはIOCから決まる原寸の走査線幅を維持します。HF-FAXは画像のPNG保存に対応しますが、現行画面にプリトリガーIQ保存ボタンはありません。

モニター音声は復調状態の確認用で、Windowsの既定出力デバイスへ送られます。音量と有効／無効はプラグイン設定で変更できます。

## よくある症状

### 信号やAPTが検出されない

対象局の周波数と放送時刻、アンテナ、USB選局を確認します。音声スペクトルで1900 Hz付近に信号があるかを見て、必要なら手動開始を使います。

### 画像が斜めになる／左右にずれる

斜めのずれは傾き補正、左右のずれは横位置を調整します。ライン毎同期補正を使う場合は、同期パルスが受信できているかを`診断`で確認します。

### 画像を保存できない

PNGの保存先への書き込み権限と空き容量を確認します。HF-FAXのPNG保存とモニター音声は利用できますが、現行画面にプリトリガーIQ保存機能はありません。
