# アマチュア無線（SSTV）

`sstv`プラグインは、USBまたはFMのSSTV信号からカラー画像を受信します。

1. MODEで「アマチュア無線（SSTV）」を選びます。
2. 受信設定に周波数をHz単位で入力します。USBではダイヤル周波数、FMでは搬送波周波数です。
3. FM信号の場合は「FM入力」をオンにして「設定を適用」を押します。
4. 受信を開始するとVISヘッダーから方式を自動判別し、画像を順次表示します。
5. 「PNG保存」で現在の画像を保存します。保存先は画面に表示されます。

対応方式はMartin M1/M2、Scottie S1/S2、Robot 36、PD120です。PNGは受信途中でも保存できます。ホストのエクスポートからもPNGを選べます。

「再待機」は画像の受信処理をリセットし、次のVISヘッダーを待ちます。周波数変更、サンプル欠落、ストリーム変更時も同期をリセットします。

VISが送られる前から受信を開始してください。途中参加での方式推定、手動開始、傾きの手動補正、音声モニター、自動保存・画像履歴はありません。画面には最新の1画像を保持し、次の画像の受信で置き換えます。USBで色がずれる場合は周波数を調整してください。

方式の時刻定義は[SSTV Handbook](https://www.sstv-handbook.com/download/sstv_04.pdf)、PD方式の走査順は[開発者G4IJEの仕様](https://www.classicsstv.com/pdmodes.php)を参照しています。
