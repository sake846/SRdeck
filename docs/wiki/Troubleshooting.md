# トラブルシューティング

## SDRが検出されない

共通確認:

1. `Settings`のSDR種別が`Auto`または目的のデバイスになっているか確認します。
2. `Detect`を再実行します。
3. 同じSDRを使用している他アプリを終了します。
4. USBケーブル、ポート、電源を確認します。

SDRplayではSDRplay API 3.xと64-bit版`sdrplay_api.dll`、RTL-SDRでは対応する64-bit版`rtlsdr.dll`とWinUSBドライバーを確認してください。

## 開始直後に停止する／処理が追いつかない

- `RATE`を下げる
- FFT解像度を下げる
- GPU FFTの有効／無効を切り替えて環境に合う方を使う
- プラグインの同時監視チャネル数を減らす
- タイトルバーの`PRC`、`GPU`、`FFT`、`WPF`を確認する

SDR、USBコントローラー、PCの組み合わせによって安定するRATEは異なります。

## 周波数がずれる

設定画面のPPM補正を調整します。既知周波数の安定した信号を基準に、少しずつ変更してください。

## 音が出ない

- 音声を出力するプラグインとプロファイルを選んでいるか
- プラグインのミュートとスケルチ
- Windowsの既定音声出力と音量
- 信号が受信帯域内にあり、十分な強度があるか

SRdeck内には出力デバイス選択やマスター音量の設定はありません。

## プラグインが表示されない

- DLL名が`SRdeckPlugin.*.dll`か
- DLLが`SRdeck.exe`と同じフォルダーにあるか
- SRdeckを完全に再起動したか
- ホストと同じAPI／パッケージバージョンを対象にしているか
- 依存DLLがそろっているか

`%LOCALAPPDATA%\SRdeck\plugins`は設定／データ用で、DLLの検索場所ではありません。

## 設定を初期化したい

SRdeckを終了し、`%LOCALAPPDATA%\SRdeck`を別の場所へ退避してから再起動します。設定、局情報、バンドプラン、プラグインデータなどが含まれるため、削除より退避を推奨します。

## まだ解決しない場合

問題報告には、SRdeckのバージョン、パッケージ種別、SDR機種、RATE、選択プラグイン、表示されたエラー、再現手順を含めてください。Analogの信号問題は、`IQ 録音 (直前3秒)`で作成されるWAVと診断JSONが調査に役立ちます。
