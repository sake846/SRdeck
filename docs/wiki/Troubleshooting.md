# トラブルシューティング

問題を早く切り分けるには、複数の設定を一度に変えず、「起動」「デバイス」「IQ入力」「チャネル抽出」「同期」「復号」「表示／保存」のどこで止まっているかを確認します。

## 最初に記録する情報

変更する前に次を控えます。

- SRdeckのバージョンと`host-only`／`with-plugins`
- Windowsの版、SDR機種、接続USBポート
- SDR種別、RATE、中心周波数、PPM、ゲイン
- MODE、プロファイル、選択チャネル
- 画面の状態メッセージ
- `PRC`、`GPU`、`FFT`、`WPF`
- プラグイン`診断`の入力、検出、同期、CRC／FEC値
- 再現する操作と時刻

設定を変えるたびに結果を比較でき、問題報告にもそのまま使えます。

## 起動しない

### .NETを要求される

.NET 10 Desktop Runtime (x64)をインストールします。SDK、ASP.NET Runtime、x86版だけではWPFホストの要件を満たさない場合があります。

### DLL不足または形式不正が表示される

1. ZIP全体を空のフォルダーへ再展開します。
2. 旧版DLLが混ざっていないか確認します。
3. 32-bit DLLと64-bitホストが混在していないか確認します。
4. ウイルス対策で隔離されたファイルがないか確認します。
5. 独自プラグインを一度退避し、公式ホストだけで起動します。

### 画面が表示されない／描画が黒い

GPU FFTをCPUへ切り替えられる場合は比較します。GPUドライバーを更新し、リモートデスクトップ、仮想環境、オーバーレイソフトの影響も確認します。設定画面まで開けない場合は、設定フォルダーをバックアップして状態を初期化します。

## SDRが検出されない

共通確認:

1. `Settings`のSDR種別を目的の機種へ明示します。
2. SRdeck以外のSDRアプリを終了します。
3. USBを抜き差しし、別ポート／ケーブルを試します。
4. USBハブを外し、PC本体へ接続します。
5. `Detect`を再実行します。
6. ベンダーソフトまたは既知のツールでデバイス単体を確認します。

### SDRplay

- SDRplay API 3.xがインストールされているか
- 64-bit版`sdrplay_api.dll`が標準インストール先にあるか
- APIサービスとドライバーが正常か
- 真正な対応製品を使用しているか
- 別アプリがAPIを占有していないか

SRdeckは標準インストール先、次に`SRdeck.exe`と同じフォルダーを検索します。

### RTL-SDR

- 互換する64-bit版`rtlsdr.dll`がアプリフォルダーにあるか
- `libusb-1.0.dll`など必要な依存DLLがあるか
- 正しいUSBインターフェースへWinUSBを設定したか
- DVB-Tなど元のドライバーへ戻っていないか
- 32-bit版DLLを置いていないか

## Start直後に停止する

1. 表示されたエラーを記録します。
2. RATEを2 MS/sへ下げます。
3. 監視チャネルを1つにします。
4. FFT解像度を8Kへ下げます。
5. 別の軽いプラグインまたはAnalogで開始します。
6. SDRを再検出します。

特定プラグインだけで停止するなら、必要帯域、最小RATE、依存DLL、プラグイン設定を確認します。すべてで停止するなら、デバイス、USB、ドライバーを優先して調べます。

## スペクトラム／ウォーターフォールが更新されない

- Start状態になっているか
- ADC／IQ状態が動いているか
- SP／WF補正で表示範囲外になっていないか
- ゲインが最低または入力が飽和していないか
- アンテナ入力やSDRplayポートが正しいか
- CPU／GPU FFTを切り替えると変化するか

`SP`と`WF`の中央ボタンで表示補正を戻せます。これらはゲインを変えません。

## 信号は見えるが復号できない

診断を上流から順に確認します。

| 診断段階 | 増えない場合に確認すること |
|---|---|
| IQ入力／ブロック | SDRストリーム、デバイス、RATE、プラグイン開始状態 |
| チャネル入力 | 中心周波数、必要帯域、オーバーレイ、RATE |
| 信号検出 | アンテナ、ゲイン、スケルチ、対象信号の有無 |
| 同期／プリアンブル | PPM、SNR、帯域、モード／プロファイル |
| 復調シンボル | 過入力、マルチパス、サンプルドロップ |
| CRC／FEC合格 | 信号品質、周波数誤差、方式設定、干渉 |
| 解析結果 | 対応メッセージ種別、フィルター、重複抑制 |

検出数だけ増えCRC不一致が多い場合は、ゲインを上下に比較し、PPM、アンテナ位置、隣接信号、RATE不足を確認します。

## 処理が追いつかない

症状は音切れ、ウォーターフォールの停止、`PRC`上昇、FFT／WPF低下、プラグインのドロップ増加です。

1. 監視チャネル数を減らします。
2. FFT解像度を下げます。
3. RATEを下げます。
4. GPU FFTとCPU FFTを比較します。
5. デジタル復調のGPU設定を`自動`またはCPUへ戻して比較します。
6. 他のGPU、USB、ディスク高負荷アプリを終了します。
7. 電源プラン、バッテリー動作、プロセス優先度を確認します。

高いRATEが必要な方式では、FFTを下げてプラグイン処理へ余裕を回す方法があります。

## 周波数がずれる

- 既知周波数の安定した信号でPPMを校正する
- SDRを温度安定させてから比較する
- 目的信号が本当に公称周波数中心か確認する
- 残留DCスパイクを信号と誤認していないか確認する
- プラグインの信号中心オフセットを確認する

HFDLは選択チャネル表示に対し信号中心が+1,440 Hzになるなど、方式上のオフセットをプラグインが表示する場合があります。

## 音が出ない／途切れる

- 音声対応プラグインか
- 音声出力、ミュート、スケルチ、音量
- Windows既定出力と音量ミキサー
- Bluetooth／USB音声機器の接続
- 信号が帯域内にあるか
- `PRC`が高くないか

既定出力を変更した後は受信を停止し、再開します。詳細は[音声出力とIQキャプチャ](Audio-and-Recording)を参照してください。

## プラグインがMODEに表示されない

1. ファイル名が`SRdeckPlugin.*.dll`か確認します。
2. `SRdeck.exe`と同じフォルダーに置きます。
3. SRdeckを完全に再起動します。
4. ホスト、Contracts、SDK、WPF、SignalProcessingの版を揃えます。
5. x64ネイティブ依存DLLを確認します。
6. クリーンな`host-only`へ対象プラグインだけを追加します。

`%LOCALAPPDATA%\SRdeck\plugins`はデータ用で、DLL検索場所ではありません。

## 地図が表示されない

- WebView2 Runtimeをインストールする
- HTTPS通信、プロキシ、ファイアウォールを確認する
- 対象が位置情報を送信／算出できているか確認する
- `一覧`や`時系列`に緯度経度があるか確認する
- ADS-Bでは受信機緯度経度を設定する
- 閉域環境では地図以外のタブを使う

背景地図が出ない場合と、対象マーカーだけが出ない場合を分けて確認してください。

## 履歴、エクスポート、IQ保存に失敗する

- `%LOCALAPPDATA%\SRdeck`と選択した出力先への書き込み権限
- ディスク空き容量
- ファイルを他アプリがロックしていないか
- パス長や使用できない文字
- IQキャプチャを受信中に実行しているか
- ウイルス対策やControlled Folder Access

IQキャプチャは`%LOCALAPPDATA%\SRdeck\plugins\<plugin-id>\captures`に保存されます。診断JSONをWAVと一緒に確認してください。

## 設定を初期化する

設定画面には状態、アプリ設定、ハードウェア設定、全設定のリセットがあります。範囲が分からない場合は、先に次のフォルダーをバックアップします。

```text
%LOCALAPPDATA%\SRdeck
```

手動で切り分ける場合:

1. SRdeckを終了します。
2. フォルダー全体を別名へ退避します。
3. SRdeckを起動し、既定設定で再現するか確認します。
4. 問題が消えたら、必要な履歴やキャプチャだけを旧フォルダーから保管します。

プラグインの`settings.json`やJSONLを受信中に編集しないでください。

## 問題報告テンプレート

```text
SRdeck version:
Package: host-only / with-plugins
Windows:
SDR / driver or API:
RATE / center frequency / PPM / gain:
Plugin / profile / channels:
Expected:
Actual:
Steps to reproduce:
Status message:
PRC / GPU / FFT / WPF:
Plugin diagnostics:
Attachments: screenshot / IQ WAV / diagnostics JSON / export
```

無線データや位置情報を添付する前に、法令、プライバシー、公開範囲を確認してください。
