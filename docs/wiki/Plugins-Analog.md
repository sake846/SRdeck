# アナログ復調プラグイン

プラグインIDは`analog`です。AM、FM、SSBのアナログ音声を復調し、ホストの共通音声出力へ送ります。

## プロファイル

| プロファイル | 主な用途 |
|---|---|
| AM | 航空無線などの振幅変調 |
| FM | FM音声。受信帯域に応じてモノラル／ステレオを処理 |
| SSB | USBまたはLSBを選択する単側波帯通信 |

NFM／WFMは独立したプロファイル名ではなく、FMの受信帯域設定で用途に合わせます。

## 設定

- プロファイル
- SSB時のUSB／LSB
- 受信帯域
- チューニングステップ
- 受信周波数
- ミュート
- AFC
- FMステレオ
- スケルチしきい値（-150～0 dBm）

周波数、プロファイル、帯域などは受信中にも変更できます。適用できない変更は元の設定へ戻され、状態メッセージに理由が表示されます。

## 音声

48 kHz、16-bit PCMとしてWindowsの既定出力デバイスへ再生されます。SRdeck内に出力デバイスやマスター音量の選択はありません。音が出ない場合はミュート、スケルチ、受信帯域、Windows側の音量を確認してください。

## 直前3秒のIQキャプチャ

受信中に`IQ 録音 (直前3秒)`を押すと、直前約3秒のIQ WAVと診断JSONを次へ保存します。

```text
%LOCALAPPDATA%\SRdeck\plugins\analog\captures
```

WAVはI/Qを左右チャネルへ格納します。中心周波数、RATE、プロファイル、帯域などは同名の`-diagnostics.json`に記録されるため、解析時は2ファイルを一緒に扱ってください。

## 基本操作

1. SDRを検出し、`MODE`で`アナログ復調`を選びます。
2. AM、FM、SSBのプロファイルと受信帯域を選びます。
3. 周波数を設定し、`Start`を押します。
4. 必要に応じてAFC、ステレオ、スケルチを調整します。
