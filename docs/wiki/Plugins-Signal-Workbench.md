# 未知信号の解析ワークベンチ

プラグイン管理で有効化し、MODEで「未知信号の解析ワークベンチ」を選び、左ペインやスペクトラムで選局して受信を開始します。解析帯域は6～200 kHzから指定できます。

- **コンスタレーション**: RMS正規化した未同期IQの散布図。
- **周波数偏移分布**: 隣接サンプルの位相差から得た瞬時周波数と、平均・5～95%幅。
- **FSK解析**: 2/4/8トーンの候補、各周波数・出現割合・標準偏差、トーン間隔、中心ずれ、外側偏移。
- **周波数判別波形**: 窓の先頭1,024点を時間順に表示してトーンの遷移を観察。
- **シンボルレート候補**: 包絡電力・位相変化・周波数変化の周期ピークから最大5件。
- **変調指数候補**: FSKトーン間隔を各レート候補で割ったh。トーン検出時はトーン遷移の周期ピークも調べます。
- **表示を保持**: グラフと候補の更新を一時的に止めて観察。

16,384サンプルが蓄積すると解析を開始します。選局・帯域変更・入力不連続時は解析窓を破棄します。候補レートは高調波などを含む推定であり、方式の確定値ではありません。コンスタレーションもシンボル同期前の表示です。

FSK候補は等間隔性、ピークの分離、分布の狭さを確認して表示します。GFSK・GMSKなどでトーンが重なる場合や短いバーストでは検出できないことがあります。混在信号も候補になり得ます。規格判定・ビット復号は行いません。

詳細は[プラグインガイド](https://github.com/sake846/SRdeckPlugins/blob/main/SRdeckPlugin.SignalWorkbench/README.ja.md)を参照してください。
