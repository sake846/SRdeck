# ACARSプラグイン

プラグインIDは`acars`です。VHF ACARSのAM-MSK信号を2400 bit/sで復調し、ARINC 618メッセージを解析します。機体登録、ラベル、ブロックID、本文、解釈結果、位置を履歴や地図へ集約します。

## 受信経路

```text
VHF ACARSチャネル
  -> 48 kS/s標準チャネルIQ
  -> 1200/2400 Hz AM-MSK
  -> NRZI / 2400 bit/s
  -> 同期文字 / 奇数パリティ / BCS
  -> ARINC 618解析
```

プラグインは選択した各チャネルに10 kHzの標準チャネルを要求します。複数チャネルを選ぶと、その全体を現在のRATEへ収めます。

## チャネル

受信設定で地域を選び、その地域に属するチャネルを複数選択できます。実装には次の候補があります。

| 地域 | 主な候補 |
|---|---|
| 日本 | 131.250、131.450、131.950 MHz |
| 世界共通 | 129.125、131.550 MHz |
| 北米 | 130.025、130.425、130.450、131.125、136.700、136.750、136.800、136.850 MHz |
| 欧州 | 131.525、131.725、131.850、136.750、136.900 MHz |

周波数の実運用は地域、空港、事業者、時間で異なります。表は受信候補であり、常時送信を保証しません。

## 最初の受信

1. VHF航空帯に合うアンテナを接続します。
2. SDRを検出し、`MODE`で`ACARS`を選びます。
3. 地域を選び、まず1チャネルだけ有効にします。
4. 必要なら`音声出力`と`スケルチ`を有効にします。
5. `Start`を押します。
6. スペクトラムのチャネルオーバーレイとバースト信号を確認します。
7. `診断`で入力、検出、同期、BCS合格の順に確認します。
8. 単一チャネルで安定したら、RATEへ収まる範囲でチャネルを追加します。

`受信ブザー`は受信イベントの通知に使えます。多数のイベントがある環境では必要に応じて無効にしてください。

## ワークスペース

### 概要

受信機体数、有効フレーム累計、正常率、最終受信、最近活動した機体を表示します。正常率が低い場合は、単に受信数を見るのではなく診断のパリティ／BCSを確認します。

### 一覧

機体別に最新メッセージを集約します。検索、受信件数、最新ラベル、解釈済み内容を確認できます。機体を選ぶと最新受信の詳細と検証結果が表示されます。

### 時系列

個々のACARSイベントを日時順に表示します。機体、ラベル、本文、解釈結果、生データHEXを確認します。メッセージは分割送信されることがあり、再構成結果と個別フレームを区別してください。

### 地図

位置を解釈できた機体だけを表示します。すべてのACARSメッセージが位置を含むわけではありません。WebView2と地図タイル通信が必要です。

### 診断

- リアルタイム処理
- 入力・選局
- 信号・チャネル
- 検出・同期・復調
- 検証・復号
- 詳細・デバッグ

`検出到達数`が増えてBCS合格が増えない場合は、ゲイン、PPM、隣接チャネル、信号品質を確認します。

## 履歴設定

| 設定 | 既定値 | 有効範囲／意味 |
|---|---:|---|
| 最大表示機数 | 500 | 50～5000 |
| 機体非表示時間 | 30分 | 1～240分 |
| 航跡保持点数 | 100 | 10～1000 |
| 履歴保持件数 | 10,000 | 100～100,000 |
| 未解読ログ | 無効 | 要確認メッセージを別ログへ保存 |

未解読ログは`acars_uninterpreted_messages.log`としてプラグインデータフォルダーで管理されます。通信内容を含む可能性があるため、共有前に確認してください。

## 履歴、エクスポート、IQ

復号履歴は次にJSONLで保存されます。

```text
%LOCALAPPDATA%\SRdeck\plugins\acars\acars-history.jsonl
```

CSV／JSONエクスポートに対応します。`IQ 録音 (直前3秒)`は次へIQ WAVと診断JSONを保存します。

```text
%LOCALAPPDATA%\SRdeck\plugins\acars\captures
```

## よくある症状

### バーストは見えるが受信0件

チャネル中心、地域、PPMを確認します。モニター音声で対象バーストが選択チャネルにあるかを比較します。

### 検出数は増えるがBCS不一致

RFゲインを上下に比較し、強い隣接信号、USBドロップ、周波数ずれを確認します。複数チャネルを1つへ減らすと原因を分離できます。

### 本文が未解読になる

ACARSフレームが正常でも、事業者固有書式、暗号化、未対応上位プロトコルは完全に解釈できないことがあります。Raw本文とHEXを保管し、受信失敗と解釈未対応を区別してください。
