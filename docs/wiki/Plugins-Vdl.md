# VDL Mode 2プラグイン

プラグインIDは`vdl`です。VHF Data Link Mode 2のD8PSK信号を受信し、AVLCフレームとACARS上位層を解析します。受信履歴、Callsign、プロトコル別集約、位置、Raw frameを表示します。

## チャネルプロファイル

| ID | 周波数 |
|---|---:|
| `136725` | 136.725 MHz |
| `136775` | 136.775 MHz |
| `136825` | 136.825 MHz |
| `136875` | 136.875 MHz |
| `136925` | 136.925 MHz |
| `136975` | 136.975 MHz |

プラグインは選択したチャネルへ16.8 kHzの標準チャネルを要求し、105 kS/sのIQを消費します。

## 受信経路

```text
VDL2チャネル
  -> 105 kS/s標準チャネルIQ
  -> D8PSK preamble / timing / carrier同期
  -> 適応等化
  -> Header FEC / Reed-Solomon / FCS
  -> AVLC
  -> ACARS上位層解析
```

適応等化器はマルチパスやチャネル歪みへ対応する処理です。診断の収束やエラー率と合わせて評価します。

## 最初の受信

1. VHF航空帯に合うアンテナを接続します。
2. SDRを検出し、`MODE`で`VDL Mode 2`を選びます。
3. 地域で使われているチャネルを1つ選びます。
4. 音声モニターとスケルチは必要に応じて設定します。
5. `Start`を押します。
6. 周波数オーバーレイ内のD8PSKバーストを確認します。
7. `診断`でpreamble、timing、carrier、FEC／RS／FCSを確認します。
8. `時系列`でAVLC、ACARS上位層、Raw frameを確認します。

受信中もチャネルを切り替えられますが、切り替え直後は同期器と等化器が新しい信号へ収束する時間を見ます。

## 受信設定

- 受信周波数: 6プロファイルから1つ
- 同期記号数: プリアンブル検証条件
- 音声モニター
- スケルチ
- 適応等化器（D8PSK）

現行設定はプリアンブル検証16記号、適応等化有効へ正規化されます。診断を比較する目的でも、ホスト／プラグインが受け付けた実効設定を状態欄で確認してください。

## ワークスペース

### 概要

受信機体数、有効フレーム、合格率、最終受信、最近の活動を表示します。

### 一覧

Callsign別と、プロトコル／種別別の集約を切り替えます。個々のイベントではなく、対象ごとの最新状態と件数を比較できます。

### 時系列

日時、周波数、Callsign、AVLC情報、ACARS本文、FEC／FCS、Raw frame HEXを表示します。解析できないフレームも、生データと検証段階を確認できます。

### 地図

位置を解釈できた機体と航跡を表示します。位置がないフレームや未対応上位層は地図に反映されません。

### 診断

- リアルタイム処理
- 入力・選局
- 信号・チャネル
- 検出・同期・復調
- 音声パイプラインの詳細
- 検証・復号

preamble後に失敗する場合はtiming／carrier／等化、復調後に失敗する場合はHeader FEC／RS／FCSを確認します。

## 履歴設定

| 設定 | 既定値 | 有効範囲／意味 |
|---|---:|---|
| 最大表示機数 | 500 | 50～5000 |
| 機体非表示時間 | 30分 | 1～240分 |
| 航跡保持点数 | 100 | 10～1000 |
| 履歴保持件数 | 10,000 | 100～100,000 |

復号済み、未解析、Raw、ACARSテキストは現行設定で保存対象になります。

## 履歴、エクスポート、IQ

内部履歴:

```text
%LOCALAPPDATA%\SRdeck\plugins\vdl\vdl-history.jsonl
```

CSV／JSONエクスポートに対応します。`IQ 録音 (直前3秒)`では2種類のWAVと診断JSONを保存します。

```text
%LOCALAPPDATA%\SRdeck\plugins\vdl\captures
  <name>-raw-iq.wav
  <name>-channel-iq.wav
  <name>-diagnostics.json
```

Raw IQはホスト広帯域入力、channel IQは抽出後105 kS/s信号です。問題がホスト同調／チャネル抽出か、VDL復調かを比較するために両方を保管してください。

## よくある症状

### 信号は見えるがpreambleが出ない

チャネル周波数、PPM、帯域、ゲインを確認します。ACARS信号など別方式をVDL2と誤認していないかも確認します。

### preamble後に同期が外れる

マルチパス、弱信号、過入力、timing／carrier、適応等化の診断を確認します。

### FEC／RS後にFCS不一致

信号品質、USBドロップ、処理負荷、干渉を確認します。Raw IQとchannel IQの両方を保存して比較できます。

### AVLCは出るが本文を解釈できない

未対応上位プロトコル、暗号化／独自書式、断片不足の可能性があります。Raw frameと検証結果を残し、RF受信失敗とプロトコル解釈未対応を分けて扱います。
