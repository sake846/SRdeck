# FT8／FT4／JT65Aプラグイン

プラグインIDは`ft8`です。UTCスロットに同期する弱信号方式FT8、FT4、JT65Aを受信し、同一帯域内の複数信号を候補探索、同期評価、LDPCまたはRS復号します。

## 対応モード

| モード | 特徴 | 重要な条件 |
|---|---|---|
| FT8 | 短い周期の弱信号通信 | UTCスロット、LDPC、複数候補 |
| FT4 | FT8より短い周期 | より正確な時刻と素早い処理 |
| JT65A | 長い周期の弱信号通信 | RS復号、十分な観測時間 |

バンドとUSBダイヤル周波数は`Bands.json`から読み込まれ、配布時は`SRdeckPlugin.Ft8.bands.json`として同梱されます。実際の運用周波数は地域、バンドプラン、コンテスト、運用慣行を確認してください。

## 時刻同期

各モードはUTCの送信スロットへ合わせて復号します。PC時計がずれていると、信号が十分強くても同期候補が減り、復号できません。

1. Windowsの時刻自動設定を有効にします。
2. 受信前に時刻同期が成功していることを確認します。
3. スロット境界に対するずれを`診断`で確認します。
4. 仮想環境やスリープ復帰後は時計の再同期を確認します。

AFCやPPMは周波数ずれを扱いますが、時計ずれは直しません。

## 最初の受信

1. 対象HF／VHFバンドに合うアンテナを接続します。
2. SDRを検出し、`MODE`で`FT8`を選びます。
3. モードとバンドを選びます。
4. まず追加バンドを選ばず、1バンドだけにします。
5. Windows時刻同期を確認します。
6. `Start`を押し、少なくとも数スロット待ちます。
7. `診断`でスロット、候補数、同期スコア、LDPC／RS結果を確認します。
8. `時系列`でCallsign、Locator、SNR、周波数オフセット、本文を確認します。

単発のスロットだけで判断せず、複数周期を観測してください。

## 受信設定

- モード: FT8／FT4／JT65A
- 主バンド: 現在の中心となるバンドプロファイル
- 追加バンド: 同じモードの候補だけを追加
- モニター音声: 選択帯域を共通音声出力へ送る
- 最小同期スコア: 0～40
- 最大候補数: 50～1000
- LDPC／RS試行回数: 10～100

候補数や反復回数を増やすと弱い信号の試行余地が増えますが、CPU／GPU負荷も増えます。まず既定値で動作させ、`PRC`と診断を比較しながら1項目ずつ変更してください。

## ワークスペース

### 概要

受信局数、復号数、最終受信、最近の送信局を表示します。短時間の数値だけでなく、選択モードの周期に対して復号が継続するかを見ます。

### 一覧

Callsign単位で最終受信、Locator、SNR、メッセージを集約します。同じ局の複数メッセージが一つの最新状態へまとめられます。

### 時系列

個々の復号イベントを表示します。UTC／ローカル時刻、送信元、宛先、Locator、SNR、周波数オフセット、Payload HEXを確認できます。

### 地図

Locatorなどから位置を得られた局を表示します。Locatorがない、解釈できない、保持期限を過ぎた局は表示されません。位置はグリッド由来であり、必ずしも送信者の正確な現在地ではありません。

### 診断

入力・選局、スロット、候補探索、同期スコア、検証・復号、詳細デバッグを確認します。候補が0なら周波数／帯域／信号、候補が多く復号0なら時計、同期しきい値、SNR、反復回数を調べます。

## 履歴設定

| 設定 | 既定値 | 有効範囲／意味 |
|---|---:|---|
| 最大表示局数 | 500 | 50～5000 |
| 局非表示時間 | 30分 | 1～240分 |
| 地図マーカー数 | 100 | 50～10,000 |
| 履歴保持件数 | 10,000 | 100～20,000 |
| 最小同期スコア | 4 | 0～40 |
| 最大候補数 | 240 | 50～1000 |
| LDPC／RS試行回数 | 35 | 10～100 |

## 履歴、エクスポート、IQ

内部履歴:

```text
%LOCALAPPDATA%\SRdeck\plugins\ft8\ft8-history.jsonl
```

CSV／JSONエクスポートに対応します。`IQ 録音 (直前20秒)`は、他の多くのプラグインより長いプリトリガーを保存します。

```text
%LOCALAPPDATA%\SRdeck\plugins\ft8\captures
```

IQ WAVと診断JSONを一緒に保管してください。

## よくある症状

### ウォーターフォールに信号があるが候補0

選択モード、バンド、USBダイヤル周波数、チャネル中心を確認します。目的信号がオーバーレイ内にあるか見ます。

### 候補はあるが復号0

Windows時刻、同期スコア、SNR、PPM、LDPC／RS試行回数を確認します。最小同期スコアを下げすぎると誤候補と負荷が増えます。

### スロットごとに処理が遅れる

追加バンド、最大候補数、反復回数、FFT解像度、RATEを減らします。次スロットへ処理が積み残されない構成を優先してください。

### 地図に出ない

メッセージにLocatorがない、Locatorを解釈できない、地図マーカー上限、WebView2／通信を確認します。
