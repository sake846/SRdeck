# Meshtasticプラグイン

> このモジュールのソースは`SRdeckPlugins`ソーススナップショットで公開されますが、公式SRdeck実行ZIPにはDLLを含めません。

プラグインIDは`meshtastic`です。Meshtasticで使われるLoRa信号を複数スロットで監視し、パケット、ノード、位置、診断情報を表示します。利用にはソースからのビルドと、同じリリースのSRdeckプラットフォームパッケージが必要です。

## 配布上の位置付け

- ソース公開: 対象
- `with-plugins`へのDLL同梱: 対象外
- `host-only`へのDLL同梱: 対象外
- ホストによる署名／サンドボックス: なし
- 利用判断: ビルドした利用者自身が地域、周波数、ライセンス、互換性を確認

ソースが存在することは、あらゆる地域・用途でのバイナリ利用を保証するものではありません。

## 受信モード

| モード | 動作 | 向いている状況 |
|---|---|---|
| `探索` | 対象帯域から候補を探索 | 使用プロファイルやスロットが不明 |
| `条件指定` | 帯域幅、プロファイル、スロットを指定 | 既知ネットワークを低負荷で監視 |

探索は便利ですが、条件指定より広い帯域と処理量を必要とする場合があります。まず地域を正しく選び、RATEと負荷を確認してください。

## 代表プロファイル

| 名前 | Spreading Factor | 帯域幅 |
|---|---:|---:|
| Long Fast | SF11 | 250 kHz |
| Long Moderate | SF11 | 125 kHz |
| Long Slow | SF12 | 125 kHz |
| Medium Slow | SF10 | 250 kHz |
| Medium Fast | SF9 | 250 kHz |
| Short Slow | SF8 | 250 kHz |
| Short Fast | SF7 | 250 kHz |

自動判定用に`AutoSF-250`、`AutoSF-125`、`AutoSF-250+125`もあります。選択可能なスロット数は、リージョン、帯域幅、現在のSDR RATEで制限されます。

## 基本操作

1. 互換する版でプラグインをビルドし、DLLと専用依存DLLを`SRdeck.exe`と同じフォルダーへ配置します。
2. SRdeckを再起動し、`MODE`で`Meshtastic`を選びます。
3. 対象地域のリージョンを選びます。
4. 使用条件が分かる場合は`条件指定`でプロファイルとスロットを1つ選びます。
5. 分からない場合だけ`探索`を使います。
6. `Start`を押し、スペクトラムオーバーレイと`診断`を確認します。
7. 単一スロットで安定してから監視範囲を増やします。

## ワークスペース

- `概要`: 最近のノード、テキストメッセージ、受信概況
- `一覧`: ノード集計、受信イベント、選択パケット、Payload HEX
- `地図`: 位置情報を持つノード
- `診断`: 受信器、スロット、同期、復調、処理状態

暗号化されたペイロードや未対応メッセージは、無線フレームを受信できても内容を表示できない場合があります。Payload HEXがあることと、アプリケーション内容を解釈できることは別です。

## 地図とプライバシー

地図には位置情報を持つノードだけが表示されます。Microsoft Edge WebView2 Runtimeと地図タイルへのネットワーク接続が必要です。

位置、ノード名、メッセージ、Payloadを保存・共有するときは、参加者のプライバシーと地域の法令を確認してください。公開ネットワークで受信できることは、内容の再公開が常に適切であることを意味しません。

## 性能調整

LoRaはSF、帯域幅、スロット候補の組み合わせで処理量が変わります。

1. 条件指定で既知プロファイルを選ぶ
2. スロット数を減らす
3. `AutoSF-250+125`より単一帯域幅を選ぶ
4. 必要範囲が収まる最小RATEにする
5. FFT解像度を下げる
6. `PRC`とスロット別診断を比較する

## よくある症状

### MODEに表示されない

公式ZIPにはDLLが含まれません。自分でビルドしたDLLの名前、配置、Host API、プラットフォームパッケージ版、依存DLLを確認してください。

### 信号は見えるがパケットにならない

リージョン、周波数スロット、帯域幅、SF候補を確認します。単一の既知プロファイルに絞り、PPMとゲインを調整してください。

### ノードは出るが地図に出ない

位置情報を送信していない、暗号化／未対応で位置を解釈できない、WebView2または地図通信に問題がある可能性があります。`一覧`で緯度経度の有無を先に確認します。
