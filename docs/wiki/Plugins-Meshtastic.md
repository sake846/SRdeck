# Meshtasticプラグイン

> このモジュールのソースは`SRdeckPlugins`ソーススナップショットで公開しますが、SRdeckのバイナリ配布には含めません。

プラグインIDは`meshtastic`です。Meshtasticで使われるLoRa信号を複数スロットで監視し、パケット、ノード、位置、診断情報を表示します。

## 受信モード

設定画面ではリージョンを選び、次のいずれかで監視条件を指定します。

- `探索`: 対象帯域から候補を探索
- `条件指定`: 帯域幅、プロファイル、スロットを明示して監視

実装されている代表プロファイル:

| 名前 | Spreading Factor | 帯域幅 |
|---|---:|---:|
| Long Fast | SF11 | 250 kHz |
| Long Moderate | SF11 | 125 kHz |
| Long Slow | SF12 | 125 kHz |
| Medium Slow | SF10 | 250 kHz |
| Medium Fast | SF9 | 250 kHz |
| Short Slow | SF8 | 250 kHz |
| Short Fast | SF7 | 250 kHz |

自動判定用に`AutoSF-250`、`AutoSF-125`、`AutoSF-250+125`もあります。選べるスロット数はリージョン、帯域幅、現在のSDR RATEに応じて制限されます。

## ワークスペース

- `概要`: 最近のノードとテキストメッセージ
- `一覧`: ノード集計、受信イベント、選択パケットの詳細／Payload Hex
- `地図`: 位置情報を持つノードを地図表示
- `診断`: 受信器、スロット、処理状態の診断

地図表示にはMicrosoft Edge WebView2 Runtimeが必要です。位置情報を送信していないノードは地図に表示されません。

## スペクトラム表示

選択中は、監視スロットを周波数オーバーレイとしてスペクトラムへ表示します。複数スロットを有効にすると負荷が増えるため、処理が追いつかない場合はRATEとのバランスを見ながらスロット数を減らしてください。

## 基本操作

1. SDRを検出し、`MODE`で`Meshtastic`を選びます。
2. リージョンを選びます。
3. `探索`、または条件指定のプロファイルとスロットを選びます。
4. `Start`を押し、`診断`で各スロットの状態を確認します。
