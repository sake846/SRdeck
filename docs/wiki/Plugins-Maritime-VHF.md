# 国際VHFプラグイン

プラグインIDは`maritime-vhf`です。国際VHFの音声を受信しながらDSC専用CH 70を監視し、有効なDSC呼出で通知された作業チャンネルへ受信機を自動追尾します。受信専用です。

## 対象信号

| 用途 | 周波数／方式 |
|---|---|
| 国際VHF音声 | Appendix 18の25 kHz音声CH、NFM、48 kS/s復調 |
| DSC | CH 70、156.525 MHz、1300/2100 Hz AFSK、1200 bit/s |
| AIS | 対象外（AISプラグインを使用） |

音声CHでは船舶送信側または海岸局送信側を選べます。CH 70は音声一覧へ含めず、AIS 1/2も扱いません。

## 最初の受信

1. VHF海上帯に対応するアンテナを接続します。
2. `MODE`で`国際VHF`を選びます。
3. 音声CHと受信側を選択します。
4. `CH 70 DSCを同時監視`と、必要なら`DSC自動追尾`を有効にします。
5. 自局宛だけを追尾したい場合は9桁の自局MMSIを入力します。
6. `Start`を押し、2つのオーバーレイと診断表示を確認します。

## DSC復号と自動追尾

DSC受信部は10ビット符号、時間ダイバーシティ、ECCを検証し、遭難、個別、グループ、全船、海域呼出からMMSI、優先度、位置、作業CHを解析します。検証を通過した呼出だけが履歴と追尾に使われます。

- MMSI空欄: 有効な呼出を宛先で限定せず追尾
- MMSI設定あり: 全局・遭難呼出と自局宛だけを追尾
- 作業CH指定あり: 指定されたCHと受信側へ選局
- 作業CHのない遭難呼出: CH 16へ選局
- `追尾解除`: 元の通常監視CHへ戻る
- 自動復帰: 音声無信号が指定時間継続すると戻る。0秒で無効

プラグインはDSC確認応答を送信せず、無線機の送信部も制御しません。法定のGMDSS設備や遭難通信手順の代替にはなりません。

## 入力帯域

ホストへ音声CHとCH 70の2つの動的チャネルIQを要求します。両周波数をSDRの入力帯域へ同時に収められない場合は音声受信を継続し、DSC監視を一時停止します。デュプレックスCHの海岸局送信側はCH 70から大きく離れるため、状態表示と必要RATEを確認してください。

## 画面

- `受信設定`: 音声CH、受信側、モニター音声、音量、スケルチ
- `DSC・自動追尾`: CH 70監視、自動追尾、自局MMSI、自動復帰
- `DSC履歴`: 優先度、送信／宛先MMSI、作業CH、解析内容
- `診断`: 音声、DSC監視、選局、追尾、信号／スケルチ、処理負荷
