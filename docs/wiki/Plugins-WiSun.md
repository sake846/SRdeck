# Wi-SUNプラグイン

プラグインIDは`wisun`です。920 MHz帯などのIEEE 802.15.4g SUN FSK信号を復調し、MACフレーム、PAN、ノード、通信履歴を表示します。

## 対応内容

- 2-FSK復調
- CRC16／CRC32検証
- IEEE 802.15.4 MAC解析
- 複数チャネルの同時監視
- 周波数オーバーレイ
- CSV／JSONエクスポート

4-FSKとPCAPエクスポートは、現在のプラグインには実装されていません。

## プロファイル

### Wi-SUN FAN

- Mode #1b: 50 kbps
- Mode #2: 100 kbps
- Mode #3: 150 kbps
- Mode #4: 200 kbps
- Mode #5: 300 kbps

### Wi-SUN HAN

- HAN A
- HAN Bルート

### Custom

中心周波数、ビットレート、SFDなどを指定できます。中心周波数の設定範囲は100 MHz～2.5 GHzです。

プロファイルごとに利用可能なチャネル候補が表示されます。複数選択はできますが、現在のSDR RATEへ収まらない構成は縮小または拒否されます。

## ワークスペース

- `概要`: 受信数や最近のフレーム
- `一覧`: PAN、ノード、通信関係とフレーム詳細
- `時系列`: 受信イベントの時間変化
- `診断`: チャネル処理、CRC、復調状態など

エクスポートは受信結果がある場合にCSVまたはJSONへ保存できます。

## 基本操作

1. SDRを検出し、`MODE`で`Wi-SUN`を選びます。
2. FAN、HAN、またはCustomプロファイルを選びます。
3. 監視チャネルを選びます。
4. `Start`を押し、`診断`でロックやCRCの状態を確認します。
