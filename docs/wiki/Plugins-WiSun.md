# Wi-SUNプラグイン

プラグインIDは`wisun`です。920 MHz帯などのIEEE 802.15.4g SUN FSK信号を復調し、PHY／MACフレーム、PAN、ノード、通信履歴を表示します。

## 対応内容

- 2-FSK復調
- CRC16／CRC32検証
- IEEE 802.15.4 MAC解析
- 複数チャネル同時監視
- 周波数オーバーレイ
- CSV／JSONエクスポート
- ヘッドレス処理

4-FSKとPCAPエクスポートは現行実装に含まれません。

## PHYプロファイル

| 区分 | 選択肢 | 通信速度／用途 |
|---|---|---|
| Wi-SUN FAN | Mode #1b | 50 kbps |
| Wi-SUN FAN | Mode #2 | 100 kbps |
| Wi-SUN FAN | Mode #3 | 150 kbps |
| Wi-SUN FAN | Mode #4 | 200 kbps |
| Wi-SUN FAN | Mode #5 | 300 kbps |
| Wi-SUN HAN | HAN Bルート | HAN向けチャネルプラン |
| Custom | 周波数、ビットレート、SFD | 既知の独自条件を指定 |

Custom周波数は100 MHz～2.5 GHz、ビットレートは50／100／150／200／300 kbps、SFDは16-bitの16進値を指定します。既定SFDは`904E`です。

標準プロファイルは通信速度に応じて有効なチャネル間隔が変わります。選択できない番号は、そのプロファイルのチャネル条件に一致しません。

## 最初の受信

1. SDRを検出し、`MODE`で`Wi-SUN`を選びます。
2. `受信有効`をオンにします。
3. 対象機器に合うPHY Mode／通信速度を選びます。
4. 既知のチャネルを1つだけ選びます。
5. `Start`を押します。
6. スペクトラムのオーバーレイと信号を確認します。
7. `診断`でチャネル入力、同期、CRCの順に確認します。
8. 単一チャネルで受信できてから、必要なチャネルを追加します。

`全選択`は広い帯域と大きな処理負荷を要求します。最初から全チャネルを選ばず、RATEへ収まる範囲とPC負荷を確認してください。

## プロファイルと周波数

FANのチャネル候補は9～37、HAN Bルートは4～17の範囲で正規化されます。方式により200、400、800 kHz相当のステップを使います。実際の対象周波数と地域の制度を確認し、受信設備を適切に使用してください。

複数チャネルを選ぶと、ホストは全チャネルを含む中心周波数と帯域を要求します。現在のRATEへ収まらない場合、選択の縮小または同調拒否が起きます。

## ワークスペース

### 概要

受信パケット数、PAN、ノード、最近の活動、全体状態を確認します。最初はCRC合格パケットが増えるかを見ます。

### 一覧

PAN単位で最新状態を集約します。PANを選ぶと、参加ノード、通信関係、最新フレームの情報を確認できます。履歴件数と対象数は同じではありません。

### 時系列

個々の受信イベントを日時順に表示します。フレーム詳細、アドレス、PAN ID、CRC状態、Raw HEX／ASCIIを確認できます。エクスポート前にフィルターと対象データを確認する場所です。

### 診断

次の段階が分かれています。

- リアルタイム処理
- 入力・選局
- 信号・チャネル
- 検出・同期・復調
- 検証・復号
- 同期生データ、イベントログ、DSPパラメーター

入力が進み同期しない場合はプロファイル、チャネル、SFD、ビットレートを確認します。同期してCRC不一致が多い場合はゲイン、PPM、干渉、信号強度を確認します。

## Custom PHY

Customは条件が既知の場合に使います。

1. 周波数をMHzで入力します。
2. 伝送速度を選びます。
3. 4桁の16進SFDを入力します。
4. まず単一信号で診断します。

SFDの形式が不正な場合は既定値へ正規化されます。Customは未知信号を自動判別する機能ではありません。

## エクスポート

受信結果があるとき、一覧／時系列からCSVまたはJSONへ保存できます。エクスポート先への権限と空き容量を確認してください。現行実装はPCAPを生成しません。

## よくある症状

### 信号はあるが同期しない

PHY Mode、通信速度、チャネル、Custom SFDを確認します。対象が4-FSKの場合、現行2-FSK復調では処理できません。

### 一部チャネルだけ動かない

選択チャネル全体がRATE内にあるか、オーバーレイが画面端へ出ていないか確認します。単一チャネルへ戻して比較してください。

### CRC不一致が多い

RFゲインを上下に比較し、PPM、アンテナ、近接する強信号、USBドロップを確認します。検出数が多いことだけで正しいプロファイルとは判断できません。

### 負荷が高い

チャネル数、RATE、FFT解像度の順に下げます。Wi-SUNの復調負荷とFFT表示負荷を分けて比較してください。
