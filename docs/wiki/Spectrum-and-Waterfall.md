# スペクトラムとウォーターフォール

スペクトラムは「今この瞬間の周波数ごとの強さ」、ウォーターフォールは「その強さが時間とともにどう変化したか」を表します。復調結果だけでなく、同調、ゲイン、干渉、処理負荷を判断するための共通計器です。

## スペクトラム

縦軸は信号強度、横軸は周波数です。表示レンジは100 dBで、設定の上端値と画面下の`SP`補正により上下位置を調整できます。

| 操作 | 結果 |
|---|---|
| `SP -` / `SP +` | 表示位置を10 dB単位で移動 |
| `SP` | SP補正を既定値へ戻す |
| 左クリック | その位置へ同調 |
| 左ドラッグ | 周波数表示をパン |
| `Ctrl`+ホイール | ポインター位置を基準にズーム |
| 横ホイール | 周波数表示をパン |

`SP`は表示だけを変え、RFゲインやデコーダー入力を変えません。ノイズフロアが画面外にあるときはSP、ADC飽和や感度不足を直すときはSDRゲインを調整します。

## ウォーターフォール

ウォーターフォールはスペクトラムの変化を時系列で並べます。連続搬送波、短いバースト、周期送信、周波数ドリフト、広帯域ノイズを見分けやすくなります。

| 操作 | 結果 |
|---|---|
| `WF -` / `WF +` | 明るさを5単位で調整 |
| `WF` | 明るさ補正を既定値へ戻す |
| 左クリック | 周波数と履歴時刻を選択 |
| 左ドラッグ | 周波数または履歴位置を移動 |
| 縦ホイール | 履歴位置を移動 |
| `Ctrl`+ホイール | 周波数方向をズーム |

現在の色モードは`カラー`です。ユーザーが選べる複数パレット、メインスペクトラムのピークホールド、任意のFFT平均化設定は現行UIにはありません。

## 周波数オーバーレイ

選択中プラグインが`IFrequencyOverlayProvider`を実装している場合、スペクトラム上に次のようなマーカーが表示されます。

- 受信チャネルの中心
- チャネル帯域
- 複数チャネルの配置
- 選択中／非選択の区別

マーカーが表示範囲の端に接している、または一部が外れている場合は、RATEかチャネル選択を見直します。プラグインの周波数設定を使うと、必要帯域を収めるようホストが中心周波数を調整します。

## FFT設定

`Settings`ではGPU FFT、FFT解像度、残留DC除去などを変更できます。解像度候補は4K、8K、16K、32K、64K、128K、256K、512K、1M、2M、4Mです。入力RATEや実行環境により実際の上限が制限されます。

1 binあたりのおおよその幅は次で求められます。

```text
周波数分解能 [Hz/bin] = RATE [sample/s] / FFTポイント数
```

例えば2 MS/s、8K FFTでは約244 Hz/binです。解像度を上げると近接信号を分離しやすくなりますが、計算量、メモリ、ウォームアップ時間が増え、更新レートは下がります。

## GPU FFTとCPU FFT

- GPU FFT: 対応環境では高解像度処理を効率化できる
- CPU FFT: GPU互換性の問題を避けられ、比較診断に使える

GPU FFTで起動失敗、黒い表示、極端な更新低下がある場合はCPUへ切り替えます。CPUで正常ならGPUドライバーや対応機能を確認します。CPUでも遅い場合はRATEとFFT解像度を下げます。

## 残留DC除去

SDRの中心周波数に固定した線や盛り上がりが見える場合、残留DC除去が有効なことがあります。ただし、中心に実在する狭帯域信号を観測するときは表示や処理への影響も比較してください。目的信号を中心から少しずらして観測する方法もあります。

## 履歴の違い

SRdeckには用途の異なる時間保持があります。

| 種類 | 代表的な長さ | 用途 |
|---|---:|---|
| 表示用ウォーターフォール | 通常約3分。プラグイン要求で変わる | 目視で過去の信号を確認 |
| ホストの短期IQ履歴 | 直近約10秒 | 選択時刻やプリトリガー処理の基盤 |
| プラグインIQキャプチャ | 直前3秒または20秒 | WAVと診断情報を保存 |
| JSONL履歴 | 設定した最大件数 | 復号済みイベントを再表示／エクスポート |

ウォーターフォールに見えている古い信号を、常にIQとして再生・保存できるわけではありません。長時間のIQ録音機能もありません。

## 波形から分かること

- 細い連続線: 搬送波、局部発振器漏れ、狭帯域信号
- 一定間隔の短い線: 周期的なバースト送信
- 幅の広い帯: 広帯域変調、ノイズ、過入力
- 時間とともに斜めに動く線: 周波数ドリフト、移動体、発振器温度変化
- 複数位置に同じ形が出る: 飽和、イメージ、相互変調の可能性

見た目だけで方式を断定せず、プラグイン診断の同期数、CRC／FEC、信号品質も合わせて判断してください。

## 負荷を下げる順序

1. 不要な監視チャネルを減らします。
2. FFT解像度を下げます。
3. RATEを下げます。
4. GPU FFTとCPU FFTを比較します。
5. 地図や更新量の多いタブから`診断`または`概要`へ移動します。
6. 他のGPU／USB高負荷アプリを終了します。

`PRC`が高く`FFT`も低い場合は処理全体、`WPF`だけが低い場合は描画側、プラグイン診断のドロップだけが増える場合は方式処理側を重点的に確認します。
