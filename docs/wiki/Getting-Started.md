# 最初の受信

このページでは、インストール済みのSRdeckで「SDRを検出し、信号を画面で確認し、プラグインの結果を読む」までを順に行います。最初は設定を増やさず、低負荷の構成で受信経路全体を確認します。

## 事前確認

- SDRplayまたはRTL-SDRをPCへ接続している
- 対応する64-bitドライバー／APIを導入している
- .NET 10 Desktop Runtime (x64)を導入している
- 同じSDRを使用する別のアプリを終了している
- `with-plugins`パッケージ、または目的のプラグインDLLを配置している

## 1. デバイスを検出する

1. SRdeckを起動します。
2. 左下の`Settings`を開きます。
3. SDR種別を`Auto`、`SDRplay`、`RTL-SDR`から選びます。
4. 設定画面を閉じ、`Detect`を押します。
5. デバイス固有のゲイン、感度、アンテナ項目が表示されることを確認します。

`Auto`はSDRplayを先に試します。複数台を接続している場合や検出に時間がかかる場合は、種別とデバイスを明示してください。検出されないときは、受信開始を繰り返すより[SDR入力設定](SDR-Source-Settings)の確認へ進む方が早く切り分けられます。

## 2. 低負荷の初期値を選ぶ

初回確認では次を目安にします。

| 項目 | 初期値の目安 | 理由 |
|---|---|---|
| `RATE` | 2 MS/s | 多くの確認に使え、USB・FFT負荷を抑えやすい |
| FFT解像度 | 8K | 分解能と更新速度のバランス |
| GPU FFT | まず既定値 | 問題がある場合だけCPUと比較 |
| 監視チャネル | 1つ | プラグイン処理の負荷を分離しやすい |
| ゲイン | 中程度 | 飽和と感度不足の両方を避ける |

RATEは観測帯域の広さです。対象信号や複数チャネルが帯域内に収まらない場合だけ4、6、8 MS/sへ上げます。ADS-Bは2 MS/s以上を必要とします。

## 3. プラグインと周波数を選ぶ

`MODE`から使用するプラグインを選びます。右側のワークスペースは選択したプラグインへ切り替わります。

| 目的 | プラグイン | 最初の設定 |
|---|---|---|
| AM／FM／SSBを聞く | アナログ復調 | 方式、受信帯域、周波数 |
| 1090 MHzの航空機を受信 | ADS-B | 受信機位置、2 MS/s以上 |
| 船舶を受信 | AIS | 固定2チャネル、音声／スケルチ |
| VHF航空データを受信 | ACARS／VDL Mode 2 | 地域または周波数 |
| HF航空データを受信 | HFDL | 地上局と時間帯に合う周波数 |
| アマチュア弱信号を受信 | FT8 | モード、バンド、正確なPC時計 |
| 920 MHz帯を解析 | Wi-SUN | PHY Modeとチャネル |

プラグイン設定で周波数を選ぶと、プラグインはホストへ同調を要求します。必要帯域が現在のRATEに収まらない場合は状態欄に理由が表示されます。

周波数を直接入力するときは、数値の後に`M`を押すとMHz、`K`を押すとkHzで確定できます。例えば`145.5`→`M`は145.5 MHz、`433920`→`K`は433.920 MHzです。`Enter`だけで確定するとHzとして扱われます。詳細は[画面構成と操作](UI-Overview#周波数入力でmkを使う)を参照してください。

## 4. 受信を開始する

1. アンテナ、周波数、プロファイル、チャネルを確認します。
2. `Start`を押します。
3. ボタン表示と状態欄が受信中へ変わることを確認します。
4. スペクトラムにノイズフロアと信号ピークが現れることを確認します。
5. ウォーターフォールが連続して流れることを確認します。
6. 右ペインの`診断`で入力、同期、復号の各段階を確認します。

画面が動くのに結果が出ない場合、SDR入力までは動作しています。次は「周波数が合っているか」「信号強度が足りるか」「同期まで到達するか」「CRC／FECで落ちているか」の順で診断します。

## 5. ゲインを調整する

ゲインは最大にすればよいわけではありません。強すぎるとADCが飽和し、目的外の強信号による相互変調や偽ピークが増えます。

1. 目的信号が見えない場合は、ゲインまたはSDRplayの感度を少し上げます。
2. スペクトラム全体が持ち上がる、平らになる、不要信号が大量に出る場合は下げます。
3. 既知周波数から一定量ずれる場合はPPM補正を調整します。
4. `SP`は表示位置の補正であり、受信ゲインではない点に注意します。

## 6. 結果を読む

多くのデジタルプラグインには共通して次のタブがあります。

- `概要`: 受信件数、対象数、最終受信、全体状態
- `一覧`: 機体、船舶、局、PANなど対象別の集約
- `時系列`: 個々の受信イベントと詳細
- `地図`: 位置が得られた対象
- `診断`: 入力、選局、同期、復調、CRC／FECの段階別状態

結果が0件でも、診断値が動いていれば原因を絞れます。入力ブロックが増えない場合はSDR／チャネル、検出だけ増える場合は周波数・帯域・信号品質、CRC不一致だけ増える場合はゲイン・PPM・マルチパスを確認します。

## 7. 停止して設定を確認する

`Start`と同じ位置の停止操作でストリームを停止します。プラグインを切り替える前やSDRを抜く前は停止してください。正常に停止できたら、次回に備えて次を記録すると再現しやすくなります。

- SDR機種とアンテナ
- RATE、中心周波数、PPM、ゲイン
- プラグインとプロファイル／チャネル
- 受信できた時間帯と信号品質
- 必要ならCSV／JSONエクスポートまたはIQキャプチャ

画面操作の詳細は[画面構成と操作](UI-Overview)、個別方式の調整は[公式プラグイン一覧](Plugins-Overview)から各ページへ進んでください。
