# はじめに

## 1. SDRを接続する

対応している入力はSDRplayとRTL-SDRです。先に対応ドライバー／APIを導入し、他のSDRアプリケーションがデバイスを使用していない状態にします。

## 2. デバイスを検出する

1. SRdeckを起動します。
2. 左下の`Settings`を開き、SDR種別を`Auto`、`SDRplay`、`RTL-SDR`から選びます。
3. `Detect`を押します。
4. 検出されたデバイスに応じて、感度、RFゲイン、AGCなどを調整します。

`Auto`はSDRplayを優先して検出します。複数のSDRや同種デバイスを使う場合は、設定画面でデバイス選択を確認してください。

## 3. RATEと周波数を設定する

左下の`RATE`から1.6、2、4、6、8 MS/sを選択できます。実際に利用できるRATEはデバイスやUSB環境に依存します。まず2 MS/s程度から試し、必要な帯域とPC負荷に合わせて変更してください。

周波数は表示上の周波数入力、スペクトラム上のクリック、または選択中プラグインからの同調要求で変更できます。

## 4. プラグインを選ぶ

`MODE`コンボボックスで使用するプラグインを選びます。右側の固定幅ワークスペースは、選択したプラグインの画面へ切り替わります。現在のメインUIは、複数プラグインをタブで同時選択する構成ではありません。

代表例:

- `アナログ復調`: AM、FM、SSBの音声受信
- `AIS`: 2チャネルの海上AIS GMSK解析
- `Wi-SUN`: 920 MHz帯IEEE 802.15.4g SUN FSK解析
- `ADS-B`: 1090 MHz Mode S Extended Squitter解析

全種類は[公式プラグイン一覧](Plugins-Overview)を参照してください。

## 5. 受信を開始する

選択したプラグインのプロファイル、周波数、チャネルなどを設定してから`Start`を押します。ボタン表示が`Running`になり、スペクトラム、ウォーターフォール、右ペインが更新されれば受信中です。

負荷が高い場合は、RATE、FFT解像度、またはプラグインで同時監視するチャネル数を下げてください。タイトルバーの`PRC`、`FFT`、`WPF`表示が調整の目安になります。
