# APRSプラグイン

MODEの「アマチュア無線（APRS）」を選び、設定で地域の周波数を選択してStartを押します。
既定は日本の144.660 MHz / AFSK 1200です。周波数は整数Hzで直接入力できます。
GMSK 9600（G3RUH）も受信できます。「日本 144.640 / 9600」で周波数と方式を設定できます。
手入力の場合は受信方式も選択して「適用」を押してください。設定は再起動後も保持します。

- **概要**: 保持中の受信と局・対象の数。
- **一覧**: 局または送信者別オブジェクト／アイテムの最新状態。
- **時系列**: CRC正常のAX.25 UIパケット、本文、メッセージ宛先とID。JSON／CSV／TNC2へ保存。
- **地図**: 解析可能な位置報告の最新位置。中継局位置ではありません。
- **診断**: 信号電力、IQ数、HDLC検証、保存キューとホスト処理状況。

非圧縮・圧縮位置、時刻付き位置、メッセージ、ステータス、オブジェクト／アイテムに対応します。
気象・テレメトリは種別と生本文を表示します。Mic-E・第三者パケットの位置は未解析です。
送信、IGate、APRS-ISは未対応です。実波での受信性能は未検証です。

履歴は `%LOCALAPPDATA%\SRdeck\plugins\aprs\aprs-history.jsonl` に既定2,000件を保持します。
地図には共通のWebView2と[地図設定](Map-and-Cache)を使用します。
信号が見えても復号しない場合は、受信方式（1200／9600）、周波数、ゲイン、周波数補正とアンテナを確認してください。
