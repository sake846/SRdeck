# 周波数ごとの活動ヒートマップ

現在の受信帯域を周波数別に監視し、しきい値を超える信号がどの時間帯に現れたかを表示します。

1. プラグイン一覧から「周波数ごとの活動ヒートマップ」を選択します。別の方式と同時に有効化することもできます。
2. 受信を開始すると、横軸に周波数、縦軸に時刻が表示されます。ウォーターフォールと同じく最新が上、過去が下です。
3. 「活動判定のしきい値」を調整します。既定は −100 dBm / FFTビンです。スペクトラム・ウォーターフォールと同じFFTと受信機校正を使い、共有データがない場合は未観測になります。
4. 「表示期間」を1時間・6時間・24時間から選択します。既定は6時間です。1時間・6時間表示は1行1分、24時間表示は1行4分です。期間を切り替えても蓄積済みの履歴は残ります。
5. 「範囲」は既定で「スペクトラムに追従」です。ズーム・パン後の周波数範囲に合わせて表示します。「受信帯域全体」へ切り替えることもできます。
6. マウスまたは矢印キーでセルの周波数・時刻・活動率・観測回数を確認します。「履歴クリア」で集計をやり直せます。

色は各周波数セルでしきい値を超えた観測の割合です。灰色は未観測、暗い青は観測済みの0%、黄色は100%です。最新の行は集計途中です。欠落区間は集計から除外し、過去の集計を保持します。

入力帯域の外まで表示すると、取得できないセルだけが灰色になります。範囲の切り替え、追従中のズーム・パンで周波数の列が変わった場合は履歴をリセットします。

256セルの各周波数範囲で、ホストの共有FFTの最大値をしきい値と比較します。独自FFTや異なるdBm換算は行わず、同じフレームを重複計上しません。FFT更新間隔より短い送信を見逃す場合があります。dBm値の精度は受信機の校正に依存します。同調・入力レート変更、しきい値変更、受信再開などで履歴をリセットします。停止時は履歴を保持します。

詳細は [プラグインREADME](https://github.com/sake846/SRdeckPlugins/tree/main/SRdeckPlugin.ActivityHeatmap) を参照してください。
