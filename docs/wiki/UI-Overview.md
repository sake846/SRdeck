# 画面構成と操作

SRdeckのメイン画面は、上部の状態表示、左側のRF表示と操作部、右側のプラグインワークスペースで構成されます。

## 上部の状態表示

タイトルバーには主に次の情報が表示されます。

- ADC／IQ入力レベル
- `PRC`: コア処理とプラグイン処理の負荷
- `GPU`: アプリケーションとGPU全体の使用状況
- `FFT`: FFT更新レート
- `WPF`: 画面描画レート

## 左側

- スペクトラム
- ウォーターフォール
- `Start`、`Detect`、`Settings`、`Exit`
- `MODE`プラグイン選択
- `RATE`サンプルレート選択
- `SP`スペクトラム表示レベル調整
- `WF`ウォーターフォール明るさ調整
- 中心周波数、AGC、感度／ゲインなどのSDR設定

`SP`または`WF`自体をクリックすると、その表示補正値を既定値へ戻します。

## 右側

右側は幅700 pxのプラグイン用ワークスペースです。`MODE`で選択した1つのプラグインのメイン画面が表示されます。プラグイン自身が、その内部に概要、一覧、地図、診断などのタブを持つ場合があります。

## マウス操作

### スペクトラム

- 左クリック: クリック位置の周波数へ同調
- 左ドラッグ: 表示周波数をパン
- `Ctrl`+ホイール: ポインター位置を基準にズーム
- 横ホイール: 表示周波数をパン

### ウォーターフォール

- 左クリック: 周波数と時刻を選択
- 左ドラッグ: 周波数または履歴位置を移動
- 縦ホイール: 履歴位置を移動
- `Ctrl`+ホイール: ポインター位置を基準にズーム

## キーボード操作

- `←` / `→`: 周波数を1ステップ移動
- `↑` / `↓`: 履歴時刻を移動
- `H` / `L`: `←` / `→`と同じ
- `K` / `J`: `↑` / `↓`と同じ
- `F`: 周波数入力を開く
- `?`: 操作ヘルプを表示／非表示

プラグイン画面内でフォーカスがある場合は、そのコントロール固有のキー操作が優先されます。
