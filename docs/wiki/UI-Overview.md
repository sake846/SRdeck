# 画面構成と操作

SRdeckのメイン画面は、上部の状態表示、左側のRF表示と共通操作、右側のプラグインワークスペースで構成されます。基本的な流れは「デバイスを検出する」「MODEとRATEを選ぶ」「周波数を合わせる」「Startする」「右ペインで結果と診断を見る」です。

## 画面全体

```text
+---------------------------------------------------------------+
| ADC / IQ | PRC | GPU | FFT | WPF                     状態表示 |
+--------------------------------------+------------------------+
|                                      | プラグイン設定         |
| スペクトラム                         +------------------------+
|                                      | 概要 / 一覧 / 時系列   |
+--------------------------------------+ 地図 / 診断            |
| ウォーターフォール                   |                        |
|                                      |                        |
+--------------------------------------+------------------------+
| Start Detect Settings | MODE | RATE | 周波数 | AGC / ゲイン   |
+---------------------------------------------------------------+
```

右ペインは幅700 pxの固定ワークスペースです。`MODE`で選んだ主プラグインが1つ表示されます。プラグイン内部には複数タブがありますが、メイン画面で複数プラグインを並べる構成ではありません。

## 上部の状態表示

| 表示 | 意味 | 見るポイント |
|---|---|---|
| ADC／IQ | 入力レベルやIQストリームの状態 | 飽和、無入力、レベルの急変 |
| `PRC` | コア処理とプラグイン処理の負荷 | 継続的に高い場合はRATEやチャネル数を下げる |
| `GPU` | アプリ／GPU全体の利用状況 | GPU FFT利用時の余裕、他アプリとの競合 |
| `FFT` | FFT更新レート | 極端に低い場合は解像度または負荷を見直す |
| `WPF` | UI描画レート | 数値処理は動くのに画面だけ遅い場合の手掛かり |

瞬間的な変動より、受信中に値が悪化し続けるかを見ます。結果が出ないときは、右ペインの`診断`も併用して「IQ入力」「チャネル抽出」「同期」「復号」のどこまで進んでいるかを確認してください。

## 左側の共通操作

| 操作 | 役割 | 注意点 |
|---|---|---|
| `Start` | SDRストリームとプラグイン処理を開始／停止 | SDRを抜く前、DLLを更新する前は停止 |
| `Detect` | 設定した種別のSDRを再検出 | ドライバー変更、抜き差し後に実行 |
| `Settings` | SDR、表示、FFT、電源、言語など | 一部は次回起動または再検出後に反映 |
| `Exit` | 受信を停止して終了 | 強制終了すると履歴の末尾が失われる可能性 |
| `MODE` | 主プラグインを選択 | 右ペインと必要な受信帯域が切り替わる |
| `RATE` | SDRの入力サンプルレート | 広いほど高負荷。デバイス対応範囲にも依存 |
| `SP -/+` | スペクトラムの表示位置を10 dB単位で補正 | RFゲインは変わらない |
| `WF -/+` | ウォーターフォールの明るさを5単位で補正 | 復調感度は変わらない |
| 中心周波数 | 受信帯域の中心を設定 | プラグイン要求で自動変更されることがある |
| AGC／感度／ゲイン | 実際の入力レベルを調整 | 上げすぎると飽和や相互変調が増える |

`SP`または`WF`の中央ボタンを押すと、その表示補正だけを既定値へ戻します。ゲイン、スケルチ、PPMは戻りません。

## スペクトラム操作

- 左クリック: クリック位置の周波数へ同調
- 左ドラッグ: 表示周波数をパン
- `Ctrl`+ホイール: ポインター位置を基準に周波数方向をズーム
- 横ホイール: 表示周波数をパン
- プラグインのマーカーを確認: 監視チャネル、中心、帯域の位置関係を把握

クリックがプラグインの有効帯域外になる場合、プラグインまたはホストが設定を補正／拒否することがあります。状態メッセージを確認してください。

## ウォーターフォール操作

- 左クリック: 周波数と履歴時刻を選択
- 左ドラッグ: 周波数または履歴位置を移動
- 縦ホイール: 履歴位置を移動
- `Ctrl`+ホイール: ポインター位置を基準に周波数方向をズーム

表示用の履歴と、IQ再処理用の保持期間は別です。古い線をクリックできても、その時点のIQを保存・再生できるとは限りません。

## キーボード操作

| キー | 操作 |
|---|---|
| `←` / `→` | 周波数を1ステップ移動 |
| `H` / `L` | 左／右と同じ |
| `↑` / `↓` | 履歴時刻を移動 |
| `K` / `J` | 上／下と同じ |
| `F` | 周波数入力を開く |
| `?` | 操作ヘルプを表示／非表示 |

TextBox、ComboBox、DataGridなどプラグイン画面内のコントロールにフォーカスがある場合は、そのコントロール固有の操作が優先されます。意図しない値変更を避けるため、周波数操作の前にRF表示をクリックしてください。

## 周波数入力でM／Kを使う

`F`キーなどで周波数入力ダイアログを開いたら、数値を入力して単位キーを押します。`M`と`K`は文字を末尾へ追加する操作ではなく、押した時点で入力値をその単位として確定します。

| 入力 | 確定キー | 設定される周波数 |
|---:|---|---:|
| `145.5` | `M` | 145.5 MHz（145,500,000 Hz） |
| `433920` | `K` | 433,920 kHz（433,920,000 Hz） |
| `145500000` | `Enter`または`H` | 145,500,000 Hz |

- `M`: MHzとして確定。画面の`MHz`ボタン、`-`キーも同じ動作
- `K`: kHzとして確定。画面の`kHz`ボタン、`+`キーも同じ動作
- `Enter`または`H`: Hzとして確定
- `*`: GHzとして確定。画面の`GHz`ボタンと同じ動作
- 小数点を使用可能。例えば`145.525`の後に`M`を押すと145.525 MHz
- `Esc`: 入力を取り消す
- `Backspace`: 末尾の1文字を削除、`Delete`: 入力をクリア

単位キーを押し忘れて`Enter`を押すと、入力値はHzとして扱われます。例えば`145.5`を入力して`Enter`を押しても145.5 MHzにはなりません。

## 右ペインの共通的な読み方

デジタル方式の多くは、設定領域の下に次のタブを持ちます。

| タブ | 内容 | 主な用途 |
|---|---|---|
| `概要` | 受信件数、対象数、成功率、最近の活動 | 受信が成立しているか短時間で確認 |
| `一覧` | 機体、船舶、局、PANなどを集約 | 対象を選び最新状態を比較 |
| `時系列` | 個々の受信イベント、検証結果、生データ | 解析、エクスポート前の確認 |
| `地図` | 位置と航跡 | 位置情報を持つ対象だけ表示 |
| `診断` | 入力、選局、信号、同期、復調、検証 | 結果が出ない原因の切り分け |

すべてのプラグインが全タブを持つわけではありません。Analogは主に`概要`と`診断`、Wi-SUNは地図を持たない構成です。

## 操作時の安全な順序

1. 受信停止中にSDR種別とRATEを選びます。
2. `Detect`でデバイスを確認します。
3. `MODE`とプラグイン設定を選びます。
4. `Start`して状態と診断を確認します。
5. 受信中の変更が拒否された場合は、停止して帯域とRATEを見直します。
6. SDRを抜く、プラグインDLLを更新する、アプリを移動する前に停止・終了します。

RF表示の詳しい調整は[スペクトラムとウォーターフォール](Spectrum-and-Waterfall)、デバイス固有項目は[SDR入力設定](SDR-Source-Settings)を参照してください。
