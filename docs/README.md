# SRdeckプラグイン文書

このディレクトリは、方式に依存しないプラグイン基盤の仕様、設計、開発手順、UI規約、試験規約を扱う。
特定の無線方式、周波数、フレーム、復号アルゴリズム、画面構成、既知ベクトル、ライセンス帰属は、
それを所有する `SRdeckPlugin.<方式名>` プロジェクト内へ記録する。

## 読む順序

1. [標準サービス設計](plugin-standard-services-architecture.md) — ホスト、共通部品、個別プラグインの責務境界
2. [インタフェース仕様](plugin-interface-specification.md) — 公開契約の意味、ライフサイクル、配送、同調、設定、互換性
3. [開発・配布ガイド](plugin-development-guide.md) — プロジェクト作成、実装、配布、レビュー手順
4. [右ペインUIデザイン指針](plugin-right-pane-design-guidelines.md) — WPF UIを提供する場合の情報設計と視覚規約
5. [回帰試験仕様](regression-test-specification.md) — 横断試験マトリクス、実行区分、受入試験、更新規則

新規プラグインを作成する場合は、開発ガイドと
[ヘッドレス生IQスターター](samples/SRdeckPlugin.Example/README.md) または
[標準チャネルIQスターター](samples/SRdeckPlugin.ChannelExample/README.md) から開始する。

## 規範性と正本

| 内容 | 正本 |
|---|---|
| コンパイル可能なAPI形状 | `SRdeckPlugin.Contracts` の公開型 |
| APIの意味、必須動作、適合条件 | `plugin-interface-specification.md` |
| SDK基底クラスと補助APIの動作 | `SRdeckPlugin.Sdk` の公開型とXMLコメント |
| WPFテーマキーと共通コントロール | `SRdeckPlugin.Wpf/Themes` と公開型 |
| 実行する回帰試験名と件数 | `SRdeck.Tests/Program.cs` |
| 方式固有の動作 | 各プラグインの実装、テスト、プロジェクト内文書 |

API形状と意味仕様のどちらか一方だけを変更してはならない。差異を発見した場合は、
公開Contracts、インタフェース仕様、コード例、適合試験を同じ変更で更新する。

## 文書へ含めるもの

- 3方式以上で共有する意味、契約、設計判断
- 共有資源、ライフサイクル、障害隔離、互換性、セキュリティの規約
- 新しい方式を追加するときに毎回必要となる手順
- 全プラグインへ適用できるUI、性能、試験、配布のチェックリスト

## 文書へ含めないもの

- 個別方式の周波数表、同期語、FEC、フレーム構造、復号パラメータ
- 特定プラグインだけのタブ、カード、履歴列、地図表示
- その時点の組み込みプラグイン一覧や手書きの全試験一覧
- GPUカーネル、校正回数、ネイティブ実装など変更頻度の高い内部詳細
- 一時的な移行監査や未解消課題の一覧

方式固有情報を横断仕様から参照する必要がある場合は、原則を本文へ記載し、具体例は所有プロジェクトの文書へリンクする。

## 更新時の確認

- 相対リンクが存在する。
- C#およびプロジェクト例がビルドできる。
- Contractsの任意インタフェースと能力フラグの説明が一致する。
- 「現行」「将来」「SDK補助」を混同していない。
- 個別方式の記述を横断文書へ複製していない。
- 回帰試験件数を手書きせず、`--list-tests` の結果を正本としている。
