# 基幹入力協調の回帰試験仕様

この仕様は、回帰試験仕様書 4.4、4.7、4.9 にある周波数同調、履歴移動、表示操作を具体化する。

## スペクトラムの横ドラッグ

- 水平方向の移動量は 40 px を 1 回の同調判定とする。
- 40 px 未満の移動は内部に残し、次の移動と合算する。正方向は中心周波数を `swipeStep` 分下げ、負方向は上げる。
- 新しい中心周波数は `swipeStep` の整数倍へ丸める。中心周波数を移動しても、移動前の絶対同調周波数は維持し、`FreqOffsetHz` を再計算する。
- `swipeStep <= 0` は入力を破棄し、中心周波数を変更しない。

## ウォーターフォールの横・縦ドラッグ

- 横方向は `deltaX * SpanHz / 100` を `StepHz` 単位で累積し、正方向で `FreqOffsetHz` を増やす。
- ViewModel のウォーターフォール操作では横方向を `PanMainView` が一度だけ適用し、サービスには横方向 0 を渡す。サービスと ViewModel の両方で横移動を適用して二重に動かしてはならない。
- `StepHz <= 0` は `RadioControl.DefaultStepHz`（1000 Hz）へフォールバックする。`SpanHz < 0` は 0 Hz として扱い、横方向の同調を発生させない。
- 縦方向は `deltaY * (maxHistorySec + 1) / 500` を累積する。正方向で履歴秒を増やし、履歴は `0..maxHistorySec` にクランプする。`maxHistorySec < 0` は 0 秒へ正規化する。
- スペクトラムとウォーターフォールのドラッグは、Shift キーの有無で倍率、方向、閾値を変えない。Shift は未定義の予約引数としてサービスへ渡さない。

## クリック、境界、通知

- スペクトラムとウォーターフォールのクリックは、受信器が表示中の場合だけ適用する。非表示の受信器では `RadioControl` を変更しない。
- 表示幅・高さが 0 以下でも座標変換は最小値 1 px を使い、例外を発生させない。クリック後は同調周波数、履歴、電源、ズーム表示を `RadioControl` へ反映する。
- マウス操作で `RadioControl` が変わった場合、ViewModel は変更後の値を `RadioControlUpdateMessage` で 1 回通知する。カーソルだけの更新は同調通知と混同しない。

## 自動試験

`Input coordination swipe contracts` は、閾値（未満・一致・超過）、累積残量、正負方向、絶対同調周波数の保持、不正な Step／Span／履歴上限、クリック可視性と表示境界、Shift 引数の不在、ViewModel の最終 `RadioControl` 通知を直接検査する。
